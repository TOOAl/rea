## 인쇄 (A4 2단)

세 PDF 모두 용지가 **A4(210×297mm)** 이고, 문제지·해설지는 한 쪽 안에서 **왼쪽 단/오른쪽 단 2단 편집**으로
조판되어 있습니다. 따라서 **A4 · 배율 100%(실제 크기) · 1쪽/장**으로 그대로 인쇄하면 2단으로 출력됩니다.
`output/인쇄안내.txt`에 양면 인쇄(긴 쪽 넘김), 여백, 컬러(25번 도표만) 등 세부 설정을 정리해 두었습니다.

## 구성 원칙

- **문항 수 / 배점**: 28문항, 2점 21문항 + 3점 7문항 = 63점 (듣기 1~17번 제외)
- **유형 배열**: EBS 수능특강 영어 유형편 01~20강 순서
  (목적 → 심경 → 주장 → 함축 → 요지 → 주제 → 제목 → 도표 → 내용일치 설명문 → 실용문 2 → 어법 → 어휘 → 빈칸 4 → 무관한 문장 → 순서 2 → 삽입 2 → 요약 → 장문 1지문 2문항 → 장문 1지문 3문항)
- **형식**: 지시문은 한국어, 지문·선택지는 영어, 5지 선다형, 선택지 ①~⑤,
  문항 번호 상자, 3점 표시, `[41~42]`·`[43~45]` 1지문 복수 문항 표기
- **지문**: 실제 외국 기사·저널·저작(WEF, UNESCO, *Nature*, *Science*, *American Psychologist*,
  *Psychological Science*, *Annals of Tourism Research*, Kerr(1975), Huron(2006) 등)의 논지를
  수능 지문 수준으로 재서술. 원문을 그대로 인용하지 않았으며, 편지·안내문·서사 3편은 동일 형식으로 창작.
- **해설지**: 문장을 의미 단위(`/`)로 끊고 단위별 우리말 뜻을 위아래로 배치한 직독직해 +
  주제·요지·정답 근거·선택지 분석·필수 어휘·구문 포인트, 그리고 문항별 원출처/EBS 연계 표.

## 문항별 원출처 요약

전체 표는 해설지 2쪽의 「지문 출처 및 EBS 수능특강·수능완성 연계 분석」에 있으며,
`meta.py`의 `SOURCES` 상수가 단일 출처(single source of truth)입니다.

## 재생성 방법

```bash
pip install reportlab pymupdf fonttools
python3 build_exam.py       # 문제지
python3 build_answer.py     # 답안지 + 정답표
python3 build_solution.py   # 해설지(직독직해)
```

- `rlib.py` : 폰트 등록 · 스타일 · 마크업 변환 (`[[3]]` → ③ 위치 표시, `[[B]]` → 빈칸)
- `content1.py` (18~28) / `content2.py` (29~40) / `content3.py` (41~45) : 문항 데이터
  (문항별 `blocks`(끊어읽기 `en` / 단위 해석 `ko`)와 `sol`(주제·요지·근거·오답·어휘))
- `meta.py` : 문항 구성표(번호·유형·배점)와 출처 메타데이터
- `fonts/` : DejaVu Serif(영문) + 나눔고딕(국문) — PDF 임베드용
