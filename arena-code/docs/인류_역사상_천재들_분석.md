# 인류 역사상 천재들 — 객관 분석 및 5층 분류 (v2.23.2)

> **원전:** 인류_역사상_천재들.md (16인) — AI 관점 4기준: 새 원리 발견·분야 넘나듦·지속 변화·제약 속 성취 + 편향 자각
> **목적:** 사실/해석/추측을 분리해 rea 5층에 배치하고, 기존 30인과 통합

## 1. 꼼꼼한 객관 분석 — 뭐가 좋고 뭐가 위험한가

### 강점
* **기준 명시:** 4기준을 먼저 밝혀서 “왜 이 16명인가”가 투명함. 기존 30인 문서가 분야별 성과 나열이었다면, 이 문서는 **선정 기준 자체를 설명**해 재현 가능
* **편향 자각:** “기록이 많이 남은 문화권에 편향”을 스스로 적시 — 30인 문서가 지적한 생존자 편향(Simonton)과 일치
* **유형화:** 5유형(규칙 새로 만듦·언어 새로 만듦·정보 흐름 바꿈·표현 새로 함·불리함 속 성취)으로 묶어, 01의 6유형(구조·통합·표상·형식·실용·변형)과 85% 호환

### 한계·위험
| 위험 | 사례 | 예방 |
|------|------|------|
| **서구·근대 편향** | 16명 중 10명이 1500년 이후 유럽·미국 | 30인의 알하이삼·마드하바·세종·소르 후아나와 균형 |
| **개인 신화** | 구텐베르크 “한 발명으로 사회 바꿈” — 사실은 중국·한국 금속활자 선행, 1450년대 실용화 과정에 후원·인쇄소 네트워크 필요 | `조건·한계` 4단 서술로 보완 |
| **제약 미화** | 베토벤 청력 상실·라마누잔 빈곤을 “천재의 증거”로 읽으면 빈곤·장애를 필수로 착각 | 01 6.2 모방금지 원칙 적용 — 고통≠창의 원천 |
| **분야 혼합** | “수학자의 왕” 같은 별칭은 당대 평가, 현대 기준으로 재검증 필요 | 별칭≠성과, 원자료(논문·악보·인쇄물)로 확인 |

### 사실/해석/추측 분리 (예시 3명)

* **사실:** 뉴턴 운동법칙·미적분, 마리 퀴리 폴로늄·라듐 발견(1903·1911 노벨), 튜링 계산 정의(1936) — 논문·특허·수상 기록 있음
* **해석:** “관찰과 상상력 결합(다빈치)”, “사고실험의 힘(아인슈타인)” — 작업 방식에 대한 해석, 다른 학자도 다르게 볼 수 있음
* **추측:** “아무도 문제라고 생각지 않았던 것을 발견” — 동기·내면은 기록 부족 시 추측으로 분류, `해석` 라벨 유지

### 5층 분류 — 어디에 배치했나

| 층 | 배치 내용 |
|----|-----------|
| 1층 기억 | 16인 출처·수상·저작 기록을 FACT로 저장. 장영실은 `기록 한계` 라벨로 “정확한 기여 범위 신중” 표시 |
| 2층 설계 | 4기준(새 원리·넘나듦·지속 변화·제약 속 성취)을 설계 체크리스트로 — 프로젝트 평가 시 “4기준 중 몇 개 만족?”으로 점수화 |
| 3층 창의 | 5유형을 01의 6유형에 매핑: 규칙=구조·통합, 언어=형식, 정보흐름=실용, 표현=형식·변형, 불리함=제약 속 성취 |
| 4층 천재 | 16명 중 6명 신규(가우스·폰 노이만·알콰리즈미·구텐베르크·베토벤·장영실)를 HISTORY_36으로 확장. 기존 30인의 조건·한계 서식에 맞춤 |
| 5층 의장 | “새 답의 언어 자체를 만드는 힘”이라는 결론을 통합 원칙으로 — 모방금지(고통 필수 아님)와 함께 |

## 2. 기존 30인과의 통합 — HISTORY 30→36

**겹치는 10명:** 레오나르도·뉴턴·아인슈타인·튜링·다윈·퀴리·라마누잔·알하이삼·셰익스피어·세종 → 기존 4단 서술 유지, 원전의 “새 언어” 관점을 해석에 1줄 추가

**새로 추가 6명 (아래 6.2 참조):**

* 가우스(수학) — 수론·통계·측지·전자기 기초, “수학자의 왕”이나 별칭 의존 금지
* 폰 노이만(계산·수학·경제) — 프로그램 내장 구조·게임이론·양자역학, 추상→현실 전환
* 알콰리즈미(수학) — 대수학 체계화, ‘알고리즘’ 어원, 바그다드 번역 운동 조건
* 구텐베르크(기술) — 금속활자 실용화, 중국의 선행과 유럽 확산 네트워크 구분
* 베토벤(음악) — 형식·표현 확장, 청력 상실 속 작곡이나 장애 미화 금지
* 장영실(공학) — 자격루·측우기·천문의기, 기록 한계로 기여 범위 신중 (원전의 주의 그대로 반영)
