## 3. 진짜 위험은 무엇인가 — 2층 설계 사무실 관점

* **목표부터 고정(클라우제비츠):** 목표가 ‘하루 수익’인지 ‘3년 자산 유지’인지에 따라 행동이 달라집니다. 목표 없이 “떨어지니까 판다”는 목표-수단 불일치입니다.
* **정보 품질 점검(손자):** 시세(사실)는 정확하지만, “왜 떨어졌나”(해석)는 아직 불완전합니다. 브로커론·금리처럼 1929년엔 있던 수치도 지금 기사엔 없습니다. 모르면 “모른다”고 표시해야 합니다.
* **병목·용량(나폴레옹):** 6일 동안 3번의 3% 변동은 시스템이 “용량 초과” 신호입니다. 마진·신용·반대매매가 병목이면 작은 뉴스에도 크게 흔들립니다.
* **중단 기준(TPS):** 미리 정해야 합니다 — “내 계좌가 -X%면 자동으로 매도 멈춤·현금 확보” 같은 규칙. 기사처럼 매일 방향이 바뀌는 장에서 즉흥 결정은 오류를 확대합니다(OODA 경고).
