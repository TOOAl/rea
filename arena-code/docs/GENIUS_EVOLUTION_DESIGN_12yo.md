### M (1주일) — 성적표와 시험지 만들기 — **시험에 불확실성 주제 포함!**
- `src/brains/registry.ts`에 `score(id), rank(), swapWithHistory()` 함수 3개 추가
- `tests/genius_evolve.test.ts` 5문제: 
  1. `코스피 사실률 100%?` (사실/추정 분리)
  2. `수능 밑줄 5개 정확?` (예쁨)
  3. ⭐ **신규: 불확실성 큰 주제** — 예: `"AI가 일자리 50% 없앤다 전망, 감정평가 시세 10% 하락 추측"` → `전제 3천재가 불확실성 3단계(확실/애매/추정)로 얼마나 잘 나누는지` 자동 체점
  4. `유튜브 썸네일 글자 안 깨짐?` (VisualQA 90+)
  5. `Council 기여도 — Gate 통과율`
- **결과:** 누가 1등인지 숫자로 보임
