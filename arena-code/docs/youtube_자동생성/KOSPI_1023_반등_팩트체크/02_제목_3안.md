# 제목 3안 — KOSPI 10.23 반등 팩트체크 (수익화·클릭 균형)

> 원칙: 자극 단정 금지, 추정↔사실 분리, “투자 권유 아님” 명시, 45자 내. 원문 제목 베끼지 않기.

## 1안 (추천 - 메인)

**[팩트체크] 코스피 4% 급락→0.3% 반등한 이유는? 5가지로 확인 | 투자 권유 아님**

- 길이: 38자 (공백 포함)
- 선택 이유: 가장 검색되는 “코스피 급락/반등” 키워드 직접 포함 + 팩트체크 프레임으로 클릭-이탈 방지 + 마지막 가드레일
- 썸네일 글자: `5305 → 5550` / `SK하이닉스 +4.42%` / `5단계 점검`
- 노출 키워드: 코스피, 코스피 급락, SK하이닉스, 솔리다임, 코스피 반등

## 2안 (보조 - 기업 연결)

**[팩트체크] SK하이닉스 4.42% 급등날, 코스피는 왜 버텼나 | 투자 권유 아님**

- 길이: 33자
- 선택 이유: SK하이닉스(127만7천원·솔리다임 상장철회) 관심층 유입, “왜” 질문형으로 교육 가치 강조
- 썸네일 글자: `SK하이닉스 +4.42%` / `5305에서 반등` / `외국인 팔고 기관 샀다`
- 노출 키워드: SK하이닉스, 솔리다임 IPO 철회, 코스피, 외국인 수급

## 3안 (보조 - 글로벌 맥락)

**[팩트체크] 美나스닥 2.6% 추락에도 코스피 반등? 6일간 3번 출렁임 | 투자 권유 아님**

- 길이: 38자
- 선택 이유: 전날 글로벌 급락(나스닥 -2.60%, 필라델피아 SOX -6.7%) 대비 국내 반등 역설로 호기심 + 6일 3번 급락 맥락 교육
- 썸네일 글자: `나스닥 -2.6%` / `코스피는 +0.3%` / `6일 3번 출렁`
- 노출 키워드: 나스닥 급락, 필라델피아 반도체, 코스피 전망 아님, 코스닥
