# DaVinci Resolve 21.3.7 전용 — KOSPI 팩트체크 영상 소스

> 네 컴퓨터에 설치된 DaVinci Resolve (21.0.3.7, 548MB)로 바로 편집하세요!

## 이 폴더가 Resolve 전용인 이유

- **WAV 오디오**: MP3보다 Resolve Fairlight에서 더 안정적 → `오디오_WAV/*.wav` (48kHz, 16bit)
- **1920x1080 PNG**: Resolve 타임라인(1920x1080 HD)에 딱 맞게 업스케일 → `_1920.png`
- **썸네일**: SVG 대신 PNG 2종 (1280x720 유튜브용 + 1920x1080 Resolve 타임라인용)
- **원본 그대로**: CapCut용 MP3/PNG도 부모 폴더에 그대로 있음

## Resolve에서 쓰는 순서

1. Resolve 실행 → 새 프로젝트 `KOSPI_1023_FactCheck`
2. Media 페이지 `Ctrl+I`로 이 폴더 전체 가져오기
3. Edit 페이지에서 새 타임라인 1920x1080 30fps 생성
4. 오디오 5개를 A1 트랙에 순서대로
5. 이미지 5개를 V1 트랙에 오디오 길이에 맞춰 늘리기 (아래 매뉴얼 09번 참고)
