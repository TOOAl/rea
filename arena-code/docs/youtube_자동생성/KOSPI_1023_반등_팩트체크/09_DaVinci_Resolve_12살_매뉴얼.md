### 5단계 — 한글 제목 넣기 (Edit, 10분)

Resolve는 SVG 한글을 못 읽어요 → **Text+로 직접 입력**해야 합니다 (이게 수익화에 유리 — 직접 제작!)

1. 좌측 `Effects Library → Titles → Text+` 드래그 → **V2** 트랙(사진 위)에 놓기
2. V2 Text+ 클립 길이를 아래 사진과 동일하게 늘리기 (예: 0:00-0:36 Text+는 `차트_6일_코스피` 위에)
3. 미리보기 화면 오른쪽 `Inspector` (오른쪽 위) → `Text` 칸에 복붙:

**구간별 복붙 텍스트 (오타 없이!):**

- **0:00 Text+ (흰색 60pt, 위쪽):** `[팩트체크] 10.23 코스피 4% 급락→0.3% 반등`
- **0:36 Text+ (노랑 36pt):** `코스피 5,550.30 (+0.30%) 장중 5,305.98 -4%`
- **1:41 Text+ (빨강 40pt):** `시세는 사실 / 이유는 추정`
- **2:11 Text+ (파랑 32pt, 5개):** `①목표고정 ②사실·추정분리 ③용량점검 ④중단기준 ⑤대안3개`
- **3:07 Text+ (흰색 48pt, 가운데):** `교육용 정보 · 투자 권유 아님`

**Inspector 설정:**

- `Font`: **Noto Sans KR** 또는 **맑은 고딕** (한글 깨지면 폰트 변경: `Font Face`에서 검색)
- `Size`: 위 숫자 참고
- `Color`: 흰색/노랑/파랑 중 선택
- `Background`: `Enabled` 체크 → 검은 반투명 (글자 잘 보이게)
- `Position`: `X:0 Y: 400` (아래) 또는 `Y: -300` (위)

**고정 자막 (전체 구간):**

- V2 맨 위에 3분43초짜리 `Text+` 하나 더 만들기
- 텍스트: `투자 권유 아님 | 출처: 한국거래소 2026.10.23` (12pt, 오른쪽 아래)
- `Inspector → Layout → Position X: 500 Y: 480` (모서리)

> ✅ 수익화 팁: 한글을 Resolve에서 직접 타이핑하면 "직접 제작" 인정 → CapCut보다 점수 높음!

### 6단계 — 자막 넣기 (Edit, 3분)

1. 타임라인 빈 곳 **오른쪽 클릭 → Import Subtitle** (Resolve 19+) 또는 `File → Import → Subtitle`
2. 부모 폴더 `05_자막.srt` 선택 → `Open`
3. `Create new subtitle track` 선택 → `Subtitle 1` 트랙 생김
4. 자막이 음성과 안 맞으면 Edit에서 드래그로 0.2초 앞뒤 이동
5. 자막 스타일: `Inspector → Caption`에서 `Font: 맑은 고딕, Size: 28, Background: 검은 반투명`

> SRT 없이 `Text+`로 직접 자막 써도 되지만, `05_자막.srt` 업로드가 유튜브 SEO에 더 좋음!

### 7단계 — 소리 다듬기 (Fairlight 페이지, 2분)

1. 아래 **Fairlight** (마이크 아이콘) 클릭
2. `A1` 믹서에서 `01_훅.wav` 볼륨 확인: `-14 LUFS` 근처 (유튜브 표준)
3. 클립 클릭 → 오른쪽 `Inspector → Volume` → **0 dB** (5개 모두 동일)
4. 필요하면 `Dynamics → Compressor` 살짝 (초보자는 건너뛰기)
5. 마지막 `05_클로징.wav` 끝에 `Fade Out` 0.5초 (Edit에서 클립 오른쪽 위 흰 점 드래그)

**배경음악 (선택, 수익화 주의!):**

- Resolve `Fairlight → Sound Library`에서 저작권 없는 음악만 사용
- 볼륨 ` -25 dB` (나레이션보다 아주 작게) → `A2` 트랙에 놓기

### 8단계 — 내보내기 (Deliver 페이지, 5분)

1. 아래 **Deliver** (로켓 아이콘) 클릭
2. 왼쪽 `Render Settings`:
   - `Custom Export` 선택
   - `Format`: **MP4**
   - `Codec`: **H.264**
   - `Resolution`: **1920x1080 HD**
   - `Frame rate`: **30**
   - `Quality`: `Restrict to 8000 Kb/s` (유튜브 권장)
   - `Audio`: **AAC, 48kHz, 320 kb/s**
   - `File Name`: `KOSPI_1023_Resolve_Final.mp4`
   - `Location`: `Browse` → 바탕화면 또는 `영상_소스/DaVinci_Resolve_용/` 선택
3. `Add to Render Queue` → 오른쪽 아래 `Start Render` 클릭
4. 1~2분 기다리면 `Render Complete` 팝업 → `OK`

**용량:** 약 60~80MB (3분43초 기준)

### 자주 묻는 질문 (Resolve 전용)

**Q: WAV가 MP3보다 왜 좋나요?**
A: Resolve Fairlight가 WAV를 더 정확하게 인식해요. MP3는 간혹 싱크가 어긋나요. 이 폴더 WAV 쓰세요!

**Q: 한글 Text+가 깨져요 (네모 □□□)**
A: `Inspector → Font`에서 `맑은 고딕`, `Noto Sans KR`, `나눔고딕` 중 하나로 바꾸세요. Windows에 한글 폰트 없으면 https://fonts.google.com/specimen/Noto+Sans+KR 에서 설치

**Q: 1920 PNG를 1080 타임라인에 넣으니 여백이 생겨요**
A: 클립 선택 → `Inspector → Transform → Zoom` 1.5로 키우거나 `Crop`으로 조정. 또는 `_1920.png`는 이미 1920x1080이라 여백 없이 꽉 찹니다

**Q: 미리보기_영상_3분.mp4를 Resolve에 넣고 바로 써도 되나요?**
A: 네! Media Pool에 넣고 A1/V1에 바로 놓으면 완성본으로 업로드 가능. 다만 직접 만든 차트 비중을 높이려면 위 5단계로 직접 조립하는 게 수익화에 더 좋아요

**Q: CapCut 가이드와 뭐가 달라요?**
A: Resolve는 `Media→Edit→Fairlight→Deliver` 4개 페이지를 이동하는 게 차이. 소리 정규화, 컬러 보정이 더 전문적이라 수익화 심사에서 가산점!

**Q: MS 영농형 태양광도 Resolve로 할 수 있나요?**
A: 네, `MS_영농형태양광_팩트체크/`에도 같은 구조로 WAV/PNG 만들어드릴게요 — 말만 하세요!
