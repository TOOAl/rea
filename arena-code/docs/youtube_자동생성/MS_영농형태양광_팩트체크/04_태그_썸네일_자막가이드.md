- 마이크로소프트

- 전북에너지 (또는 에너지전환)

**금지 태그 (수익화 위험):** 대박, 무조건수익, 긴급투자, 정부극찬, 좌파우파

## 썸네일 제작 — 1280x720 JPG (12살 따라하기)

### 원칙
- AI 배경은 텍스트 없이 (오타 방지) + 한글 텍스트는 SVG 코드로 합성
- 3색 이하, 4단어 이상 금지, “투자 권유 아님” 배지 필수

### 구성 (직접 만든 예시)
- **배경:** 논밭 위 태양광 패널 일러스트 (AI 생성, 텍스트 없음) — 밝은 하늘, 녹색 벼, 은색 패널
- **왼쪽 큰 텍스트 (SVG):** “논 위에 태양광?” (36px, 진한 네이비, 흰 테두리)
- **오른쪽 작은 그래프 (SVG):** 막대 2개 — 40GW / 19GW (파랑/회색)
- **우하단 배지:** “투자 권유 아님” (8px, 노랑 배경, 검은 글씨)
- **우상단 출처:** 전주MBC 2026.10.23 (6px)

### 파일 세트
- `ms_agrivoltaic_thumbnail_bg.png` (AI 생성 1280x720, 텍스트 없음)
- `ms_agrivoltaic_thumbnail_overlay.svg` (텍스트 레이어 — 코드로 렌더링)
- 합성: `Pillow`로 합쳐 `ms_thumbnail_final.jpg` (237KB, 1280x720) 내보내기
- 검증: 한글 오타 0 확인 (논 위에 태양광 / 영농형 태양광 / 투자 권유 아님 / 40GW)

### 금지
- “대박 수익”, “지금 사야”, 정치인 얼굴 합성, 돈뭉치 이미지 → 선정성·오해

## 자막(.srt) 원칙

- 전체 대본을 SRT로 업로드 — 자동자막 끄기 (광고 적합성↑)
- 모든 수치 뒤에 `[출처: 전주MBC 2026.10.23]` 또는 `[출처: 전력거래소 추정치]` 병기
- “따르면”, “~라고 해석” 등 인용 표현 사용 — 단정 금지
- 예시:
```
1
00:00:00,000 --> 00:00:05,000
마이크로소프트가 한국 시골 논밭을 주목하고 있습니다. [출처: 전주MBC 2026.10.23]

2
00:00:25,000 --> 00:00:32,000
MS 최고지속가능성책임자 멜라니 나카가와가 10월 8일 레드먼드에서 인터뷰했습니다.
```
