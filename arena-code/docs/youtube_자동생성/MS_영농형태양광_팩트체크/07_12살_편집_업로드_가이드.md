# 12살도 따라하는 편집·업로드 가이드 — MS 영농형 태양광 팩트체크 편

> 이 가이드는 스마트폰 1개 + 무료 앱 2개(CapCut, YouTube Studio)로 30분 만에 끝내는 방법입니다. 어려운 용어는 12살 설명으로 풀었어요.

---

## 준비물 (5분)

- [ ] 스마트폰 (아이폰/갤럭시 모두)
- [ ] 무료 앱: **CapCut** (영상 편집) / **YouTube Studio** (업로드) — 앱스토어에서 설치
- [ ] 우리 파일 7종: `01_대본_수익화.md`, `02_제목_3안.md`, `03_설명란.txt`, `05_자막.srt`, `06_수익화_체크리스트.md` + 썸네일 2개(배경+오버레이)
- [ ] 이어폰 (내 목소리 녹음할 때 잡음 줄임)

---

## 1단계: 목소리 녹음하기 (8분)

### 12살 설명: “기사 내용을 내 말로 읽는 시간”

1. CapCut 열기 → `새 프로젝트` → `텍스트` → `텍스트 읽기`는 쓰지 말고, **내 목소리**를 쓰는 게 수익화에 중요해요 (AI 목소리만 쓰면 재사용 의심).
2. 대본 `01_대본_수익화.md`를 스마트폰 메모장에 복사 → 한 문단씩 천천히 읽기
3. **속도:** 1분에 150자 정도 (초등학교 읽기 속도). 8분이면 약 1,200자.
4. **꿀팁:** 어려운 단어(영농형·지속가능성)는 “논 위에 태양광” “지구를 지키는 책임자”로 바꿔 읽어도 돼요 — 대본에 이미 12살 버전이 있어요.
5. 녹음 후 저장: `ms_voice.m4a`

**체크:** 내 목소리 + 기사 인용 15% 이하 = 수익화 1등 공신!

---

## 2단계: 화면 만들기 (10분) — 직접 만든 그림이 70%

### 12살 설명: “남의 사진 1장만 쓰고, 나머지는 내가 그린 표”

**CapCut에서:**
1. `비디오` → `배경` → 초록색 논밭 사진 1장 넣기 (Pexels 무료 사진 검색: “rice paddy”)
2. 그 위에 `스티커` → `도형` → 흰색 네모 3개로 태양광 패널 만들기 (직접 만든 그림!)
3. `텍스트`로 추가:
   - “논 위에 태양광?” (큰 글씨, 네이비, 흰 테두리)
   - “MS 40GW / 19GW” (작은 그래프 — CapCut 차트 스티커로 막대 2개 만들기)
   - 우하단에 “투자 권유 아님” (노란 배지)
4. **금지:** 썸네일에 “대박 수익” “지금 사라” 쓰면 수익 정지!

**그래프 2개 만들기 (SVG 대신 CapCut으로):**
- 그래프 A: MS 40GW vs 가동 19GW — CapCut `차트` 스티커로 막대 40 / 19
- 그래프 B: 30년 타임라인 — 2026 → 2056 가로선 + 체크포인트 3개

**저장:** `ms_video_draft.mp4` (녹음+화면 합친 초안)

---

## 3단계: 자막 넣기 (7분)

### 12살 설명: “귀가 안 들려도 글자로 보는 친구 위해”

1. CapCut → `텍스트` → `자동 자막` → `생성` → 한국어 선택 → 생성 후 **반드시 수정**
   - 자동 자막은 “영농형”을 “영농형”으로 잘 못 알아들으니, `05_자막.srt`를 보고 고치기
2. 또는 `05_자막.srt` 파일을 CapCut에 넣기: `자막` → `가져오기` → `05_자막.srt` 선택 (가장 정확!)
3. 모든 숫자에 출처 붙이기:
   - “40GW” → “40GW [출처: 전주MBC 2026.10.23]” (작게, 회색)
4. 하단에 고정 자막 1줄 추가 (영상 전체):
   - “*본 영상은 교육용 정보이며 투자 조언이 아닙니다*” — 8pt, 흰색, 검은 배경

**저장:** `ms_final.mp4` (1080p, 16:9 권장 — Shorts가 아니면 가로가 수익에 유리)

---

## 4단계: 썸네일 만들기 (5분)

### 12살 설명: “유튜브에서 제일 먼저 보이는 사진”

1. CapCut에서 `캔버스` → `16:9` (1280x720) 만들기
2. 배경: 논밭 위 태양광 일러스트 (위 2단계에서 만든 것 재사용)
3. 텍스트 3개만:
   - “논 위에 태양광?” (왼쪽 크게)
   - “40GW / 19GW” (오른쪽 작게)
   - “투자 권유 아님” (우하단 노랑 배지)
4. **내보내기:** JPG로 저장 → `ms_thumbnail.jpg` (1280x720, 2MB 이하)

**검증:** 친구에게 보여주고 “오타 있어?” 물어보기 — “논 위에” “투자 권유 아님” 오타 0 확인!

---

## 5단계: 유튜브에 올리기 (10분) — 제일 중요!

### A. Studio 들어가기
1. 스마트폰에서 **YouTube Studio** 앱 열기 (또는 컴퓨터에서 studio.youtube.com)
2. 오른쪽 `+` → `동영상 업로드` → `ms_final.mp4` 선택

### B. 제목 붙이기 (복붙)
1. `02_제목_3안.md`에서 1안 복사:
   ```
   [팩트체크] MS가 “한국 영농형 태양광, 놀라운 진전”이라 한 이유? 5단계로 확인 | 투자 권유 아님
   ```
2. 제목 길이가 2줄 넘으면 3안으로 바꾸기 (짧은 게 클릭률 높음)

### C. 설명란 붙이기 (복붙)
1. `03_설명란.txt` 전체 복사 → 설명란에 붙여넣기
2. **반드시 확인 3곳:**
   - 첫 줄 “본 영상은 교육용 정보이며...” 있는가?
   - 원문 링크 2개 클릭되는가? (https://n.news.naver.com/article/659/0000048060 + http://www.jmbc.co.kr/news/view/69092)
   - 타임스탬프 6개가 파란 링크로 변하는가? (00:00 형식 지켜야 자동 챕터 생성)

### D. 썸네일·자막·태그 넣기
1. `썸네일` → `맞춤 썸네일 업로드` → `ms_thumbnail.jpg` 선택
2. `자막` → `자막 추가` → `파일 업로드` → `05_자막.srt` 선택 → 언어 “한국어” → 자동자막 **끄기** (중복 방지)
3. `태그` (보이지 않으면 `더보기`)에 복붙:
   ```
   팩트체크, 영농형태양광, 마이크로소프트, 재생에너지, 전북에너지
   ```
   - 자극 태그(대박·긴급투자) 넣으면 수익 정지!

### E. 설정 3개
1. `카테고리`: 교육
2. `언어`: 한국어
3. `공개 범위`: 처음엔 `비공개`로 저장 → 미리보기 확인 후 `공개` (실수 방지)

### F. 수익화 체크 (공개 전!)
1. Studio → `수익 창출` → `자가진단` 설문:
   - “재사용 콘텐츠인가요?” → **아니오** (직접 제작 70% 이상, 인용 15% 이하)
   - “선정적 표현 있나요?” → **아니오** (대박·보장 없음)
   - “금융 조언인가요?” → **아니오** (투자 권유 아님 고지 4곳)
2. `06_수익화_체크리스트.md`를 PDF로 변환해 첨부 (근거 메모)

---

## 6단계: 공개 후 할 일 (2분)

1. 댓글 1개 고정:
   ```
   원문과 5단계 체크리스트는 더보기란에 있습니다. 투자 권유가 아니니, 토지·설치는 농림부·한전 자료로 재확인하세요!
   ```
2. “투자하세요” 댓글 달리면 → ❤️ 금지, 📌 고정 금지, 대신 위 문장으로 답글
3. 24시간 후 `분석` → `노출 클릭률` 확인: 2% 미만이면 제목을 2안으로 교체

## 실패하면? 3가지 SOS

- **업로드가 안 돼요:** 동영상 2GB 넘나요? CapCut에서 1080p→720p로 다시 내보내기
- **수익 창출이 안 돼요:** “재사용” 판정 → 기사 문장 그대로 읽은 부분이 1분 넘나? 직접 그래프 2개가 있나? 체크리스트 다시 보기
- **댓글에 욕이 달려요:** 삭제하지 말고 `신고` → `악성 댓글`로 신고, 정치 공방에는 답글 달지 않기
