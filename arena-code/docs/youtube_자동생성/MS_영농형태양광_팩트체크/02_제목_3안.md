## 1안 (메인 추천 — 팩트체크형)
[팩트체크] MS가 “한국 영농형 태양광, 놀라운 진전”이라 한 이유? 5단계로 확인 | 투자 권유 아님

- 모바일 미리보기: 2줄에서 잘림 없음 확인

## 2안 (비교형 — 시리즈 연결)
[팩트체크] 영농형 태양광 30년 병행 vs 일반 태양광, 무엇이 다른가 | MS 40GW 팩트체크

- 검색 키워드: 영농형 태양광, 30년 병행, MS 40GW

- 장점: “논 위에 태양광” 직관적 표현, 초보자 유입, 팩트체크 톤 유지

### 제목으로 쓰면 안 되는 예 (수익화 위험)

- ❌ “MS, 한국에 40GW 투자 확정! 지금 논 사야 한다” → 단정+투자권유 → 수익정지
- ❌ “영농형 태양광 대박, 30년 무조건 수익” → 과장+보장 → 허위정보
- ❌ “정부 극찬! 좌파/우파 찬양” → 정치 편향 → 논란성

### 썸네일과 제목 짝 맞추기

- 제목·썸네일이 서로 다른 주장을 하면 “낚시”로 신고 위험 → 일치시키기
