## 1. REA/Ghidra가 본 최고 에이전트의 비밀

### Claude Code 2.0 (nodes 5000, edges 12000, queryLoop 9단계)
- **강점:** 컨텍스트 9.5 — 5단계 Compaction (BudgetReduction→Snip→Microcompact→Collapse→Auto-Compact 6500토큰 서브에이전트) + Prompt Caching
- **약점:** 리버스 3.0 없음
- **REA trace:** `Settings→State→Context→Compaction5→Model→Dispatch→Gate→Execution→Stop` 중 Compaction5가 프레임 초과를 방지. rea는 2단계만 있었음 → -0.3점 원인
- **Ghidra 휴리스틱:** `compaction` 문자열이 5번 등장, `auto-compact`는 별도 스레드(서브에이전트)로 실행 — 우리 `context.ts`는 단일 패스

### Mem0/Letta/Zep (기억 전문)
- Mem0 3스코프(user/agent/run) + ADD/UPDATE/DELETE/NOOP, Letta self-edit, Zep triple+reference_time
- rea `bank.ts`는 스코프/TTL/신뢰도/그래프/자가편집 v2로 이미 6.5→8.0 설계 완료, 코드는 `MemoryEntry.scope/confidence/ttlDays`까지 구현됨 → 이번 훈련에서는 컨텍스트를 우선

### Codex+Orca Fleet / Cursor Serena
- Fleet 8.5는 worktree 격리+intra-loop wave, rea는 H1~H5+O1~O3까지 완료, 남은 0.5는 wave → 다음 PR
- Serena/Context7은 이미 `src/tools/serena.ts` + `src/harness2/context7.ts`로 흡수 완료
