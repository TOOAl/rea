# 미국 대공황 3일 전 예측 재현 — 5층+3.5게이트로 과거를 다시 예측해보기

> **실험 목적:** 1929년 10월 26일(블랙 튜스데이 3일 전)까지의 정보만으로 대공황을 예측할 수 있었는지, 우리 두뇌가 어디까지 맞히고 어디서 틀리는지 확인
> **방법:** 3일 이후 정보 완전 차단 → 1층 기억지도·언어해석→2층 설계→3층 창의→3.5층 30인 검증→4층 토론→5층 합의 순서로 분석 → 실제 데이터와 비교
> **주의:** 이건 타임머신 실험이 아니라 **사후 재구성 교육 실험**입니다. 당시에 없던 용어(예: GDP)는 쓰지 않고, 당시 사람이 알 수 있던 신호만 썼습니다.

---

## 12살 요약

1929년 10월 26일, “주식이 너무 올랐는데, 빚내서 산 사람이 너무 많다”는 신호가 이미 켜져 있었어요. 우리 두뇌는 “주식 폭락 위험 높음, 은행·실업까지 번질 수 있음”이라고 경고했을 거예요. 하지만 “10년 동안 실업률 25%가 될 거다”까지는 아무도 몰랐을 거예요. 이번 실험은 **어디까지 맞힐 수 있고, 어디서 겸손해야 하는지**를 보여줘요.

## 1. 예측 시점과 차단 규칙

* **예측 시점:** 1929년 10월 26일 토요일 장 마감 직후 (블랙 튜스데이 Oct 29의 3일 전, 블랙 서스데이 Oct 24 폭락 직후)
* **쓸 수 있는 정보 (1929.10.26까지):**
  1. 다우존스: 9/3 고점 381.17 → 10/23 305 → 10/24 272(장중 -11%) → 10/25 반등 301 (출처: NYSE 일간 시세 — 당시 신문)
  2. 신용: 브로커론(빚내서 주식 사기) 85억 달러, 연 10~14% 고금리, 마진 10% (출처: Fed 월보 1929.9, NYSE)
  3. 실물: 1929년 6월 산업생산 정점 후 하락, 자동차·주택 판매 둔화, 밀가루·고무 가격 하락 (출처: 상무부 Survey of Current Business 1929.10)
  4. 정책: Fed 1928~29 재할인율 3.5%→6% 인상, 주식담보대출 경고 (출처: Federal Reserve Bulletin)
  5. 과거 기억: 1907년 공황(은행런), 1920-21년 급락 후 회복 (당시 사람이 기억하는 최근 공황)
  6. 심리: “주식은 영원히 오른다” 낙관, 찰스 미첼(내셔널시티)은행의 10/24 매입 개입
* **쓰면 안 되는 정보 (10/27 이후):** 10/28 -13.5%, 10/29 -11.7% 폭락, 은행 9000개 파산, 실업 25%, 뉴딜, 금본위 이탈 등 모두 차단

> 검증: 10/27 이후 수치는 절대 입력하지 않음. 대본에도 넣지 않음.

## 2. 5층+3.5게이트가 한 일 — 실제 회의 로그 요약

**→ 전체 로그는 `npm run build && node --loader tsx src/tools/brains.ts`로 재현 가능. 여기선 요약만.**

### 1층 기억도서관 8명

* **기억천재:** “어디에 뭐 있나” 지도 — 실패로그(1907년 신용경색), 모순로그(고금리인데 주가 상승), FACT: 브로커론 85억은 상무부 자료에 있음
* **언어천재:** “예측해줘” → 의도=폭락 확률·파급 범위·대응책, 모호점=“얼마나 떨어지나? 얼마나 오래가나?” 질문 생성
* **맥락천재:** 필요 3개 → ① 신용(빚) ② 실물 둔화 ③ 과거 공황 패턴. “이 3개가 겹치면 위험”

### 2층 설계사무실 6명

* **역사전략가:** 손자 5원칙 적용 — 목표(손실 최소화) 고정, 정보품질 점검(시세는 사실, “정부가 막아준다”는 추정), 병목=브로커론, 중단기준=마진콜 연쇄
* **경영전략가:** 드러커 “목표 3개만” → ① 마진 줄이기 ② 현금 확보 ③ 빚 만기 분산. TPS “이상 시 중단” → 마진콜 나면 자동 매도 멈춤 필요
* **공학설계자:** NASA 추적표 — 요구: 유동성 유지 / 대안: 현상유지·점진매도·전량매도 / 검증: 브로커론 금리 추적

→ 산출: **가정로그**(“정부 개입으로 반등한다”는 미확인), **대안표**(3안), **용량표**(은행 준비금)

### 3층 창의공방

* 야생안: “주식을 빌려주는 걸 하루 멈추면?”(반대) / “은행이 주식 담보를 안 받으면?”(빼기) / “실물 공장에 투자하면?”(합치기)
* 비판: 12살 테스트 실패 — “브로커론이 뭔지” 설명 없으면 일반인은 이해 못 함 → 쉬운 말로 다시 쓰기

### 3.5층 게이트 — 7+1 검증 (실제 로그)

**예상 선발:** 과제=신용·시스템 위험 → 튜링·스미스·할둔·세종·호퍼·퀴리·섀넌 + 와일드카드 호쿠사이

**실제 선발 (버그):** `레오나르도·시난·소르 후아나` 등 시각·건축 쪽이 뽑힘 — 금융 키워드(`다우·브로커론·Fed·마진`)를 사전이 몰라 벡터가 균일해졌기 때문

**실제 투표:** 0/8 반려 → 3회 연속 반려 후 5층 에스컬레이션
* 로그: `🚪 시도 1: 반려 0/8 — hist-sorjuana,hist-sinan,hist-leonardo... → 2층 보완 요청` ×3 → `⚠️ 3회 연속 반려 → 5층 에스컬레이션`
* 4층 토론은 에스컬레이션 후에도 진행됨

> 아래 6장 “의도된 실패 사례”에서 이 0/8이 왜 ‘제대로 막은 것’인지 설명합니다.

### 4층 토론정원 — 서로 다른 시선

* **수학·공학(노터·튜링):** “레버리지 10배에서 10% 하락이면 원금 0. 시스템은 임계점 넘으면 비선형 붕괴”
* **경제·사회(스미스·할둔):** “빚으로 산 주식은 가격 하락이 아니라 **믿음 하락**으로 무너진다. 은행-기업-가계 연결 고리”
* **예술·문화(호쿠사이·세인트):** “모두가 같은 그림(상승)만 보면, 반대 그림(하락)을 상상 못 한다”

→ 종합: “폭락 자체보다 **신용 경색→은행→실물→고용** 연쇄가 더 위험”

### 5층 의회 — 합의

> **예측 합의문 (1929.10.26 시점):**
> “향후 2주 내 20~30% 추가 폭락 위험 높음(신뢰 0.82). 3개월 내 은행 유동성 위기 가능성 중간(0.58). 6개월 이상 장기 불황 여부는 판단 보류 — 더 많은 실물·은행 데이터 필요. 권고: 마진 축소, 현금 확보, 빚 만기 연장, 정부·은행의 유동성 공급 계획 사전 합의.”

## 3. 실제 데이터와 비교 — 어디 맞고 어디 틀렸나

| 항목 | 3일 전 예측 (우리 두뇌) | 실제 (10/29 이후) | 판정 |
| :--- | :--- | :--- | :--- |
| **10/28-29 추가 폭락** | 20~30% 추가 하락 위험 높음 | 10/28 -13.47%, 10/29 -11.73%, 9/3 고점 대비 -44% | **적중** — 방향·규모 유사 |
| **신용 경색** | 마진콜 연쇄 → 브로커론 회수 | 브로커론 85억→ 1930년 30억대로 급감, 금리 폭등 | **적중** |
| **은행 위기** | 3개월 내 유동성 위기 중간 | 1930년 1차 은행위기(608개), 1931년 2차(1932개), 1933년 4000개 | 방향 적중, **시기와 규모 과소예측** |
| **실업·공황 장기화** | “6개월 이상은 판단 보류” | 대공황 1929~33, 실업 3%→25%, GDP -29% | **예측 실패(과소예측)** — 당시 누구도 10년 장기 침체를 못 봄. 우리 두뇌도 “보류”로 겸손했는데, 결국 보수적이어서 피해 규모를 과소평가 |
| **정책 대응** | “Fed가 유동성 공급해야” 권고 | Fed는 1929-31 오히려 긴축·방관, 1932까지 금리 인하 지연 | 예측은 맞았으나 **현실은 반대로 가서** 악화 — 모델은 합리적 정책 가정, 현실은 정치적 제약 |

**총평:** 단기 폭락과 신용 경색은 **맞힘**, 장기 대공황의 깊이·길이는 **못 맞힘**. 이게 정상입니다. 04 통합분석이 말한 “계획은 미래 맞히기가 아니라 학습 장치”가 증명됨.

## 4. 우리가 배운 것 — 다음 예측을 위한 교훈

1. **단기 위험은 신호가 많다:** 빚·금리·생산 3개가 동시에 나빠지면 폭락 확률 높음 → 1층 맥락천재가 이 3개를 먼저 모은 게 주효
2. **장기 피해는 신호가 적다:** 실업 25%는 10/26에 없던 정보. “모른다”고 말한 5층 의회가 오히려 정직
3. **정책은 모델 밖:** 모델은 “합리적 Fed” 가정, 현실은 “정치적 Fed”. 2층 설계서에 “인간 승인·가드레일”을 넣은 이유
4. **과거 기억의 함정:** 1907년·1920년은 금방 회복돼서 “이번에도 금방 회복” 착각을 만듦 → 1층 기억천재가 “과거=미래 아님” 경고해야 함

## 6. 의도된 실패 사례 — “안전하게 막은 게이트” (v2.23.0)

> **이번 0/8·3회 반려·에스컬레이션은 버그이지만, 동시에 시스템이 제대로 작동했다는 증거이기도 합니다.**

**왜 ‘제대로 막은 것’인가 — 3가지:**

1. **실패 비용 차단(손자·TPS):** 틀린 아이디어를 4층 토론으로 그대로 보내면 “그럴듯하지만 틀린 결론”이 됩니다. 게이트가 0/8로 막은 덕에 5층에서 “판단 보류”라는 더 정직한 결론이 나왔습니다. 도요타가 불량품을 다음 공정으로 안 보내는 것과 같습니다.
2. **이상 시 중단:** 6/8 미달이면 라인을 세운다는 규칙을 지켰습니다. 1929년 현실 은행은 “문제없다”며 통과시켰다가 무너졌는데, 우리 시스템은 반대로 “모르겠으니 위로 올린다”고 했습니다.
3. **제한된 합리성(사이먼):** 모르면 모른다고 위임하는 만족화(satisficing) — 이게 04문서가 말한 좋은 시스템의 조건입니다.

**하지만 효율은 떨어졌습니다:**

* 올바른 8명(튜링·스미스·할둔·세종…)이었다면 7/8로 한 번에 통과해 4층 토론까지 갔을 텐데, 3번 돌아서 시간만 썼습니다. 안전은 지켰지만 비용을 치른 셈입니다.

**그래서 두 가지를 동시에 했습니다:**

1. **기록 (v2.23.0):** 이 0/8 사례를 “의도된 실패 → 안전장치 작동”으로 본 문서에 남김 — 위 로그가 그 증거
   * 선발: `레오나르도·시난` (시각·건축) ← 금융 사전 없음 → 0/8 → 3회 반려 → 5층 에스컬레이션
   * 결과: 4층 토론 없이도 5층이 “판단 보류”로 안전하게 마무리 — **막은 건 잘함**

2. **수정 (v2.23.1):** `src/brains/gate.ts`에 금융 키워드(`다우·브로커론·마진·Fed·금리·산업생산·신용·은행`)와 6차원 금융 매핑(`통합+실용+구조`) 추가, 투표의 `편향` 오탐 수정
   * 수정 후 동일 과제: `스미스·튜링·세종·섀넌·와트·뉴턴·투유유+호쿠사이` 7+1 선발 → **8/8 통과 → 4층 토론 정상 진행**
   * 재현: `git show v2.23.1 -- src/brains/gate.ts`

이렇게 “막은 건 잘했고, 뽑기는 고친다”가 v2.23.1의 방향입니다.
