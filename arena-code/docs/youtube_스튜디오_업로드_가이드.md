# YouTube Studio 업로드 가이드 — 코스피 급락 편 (복붙용)

## 1. 자막 업로드 (Studio → 자막)
- 파일: `youtube_코스피_급락_자막.srt` (UTF-8, 45 cues)
- 업로드 경로: YouTube Studio > 자막 > 한국어 추가 > 파일 업로드 > 시간 코드 있음
- 확인: 자동자막 끄기, 수동 자막만 유지 — 광고 적합성 ↑, 오탈자 방지
- 팁: 업로드 후 Studio 자막 편집기에서 00:01:33 “6일 전 5,554와 오늘 5,533은 거의 같다” 줄 바꿈 확인

## 2. 썸네일 JPG 합성 (Studio → 썸네일)
- 최종 파일: `docs/images/kospi_thumbnail_final.jpg` (1280×720, 237KB, JPG)
- 원본 세트: `kospi_factcheck_thumbnail.png` (AI 텍스트-프리 배경) + `kospi_thumbnail_overlay.svg` (코드 텍스트) → PIL 합성
- 검증: 한글 오타 0 (팩트체크/코스피 6일 새 3번 급락/숫자 뒤 5단계 확인법/투자 권유 아님)
- 업로드: Studio > 썸네일 > 맞춤 썸네일 업로드 > 1280×720 선택
- 모바일 미리보기: 제목 2줄이 잘리지 않는지 확인 (우하단 재생 시간 겹침 없음)

## 3. 설명란 붙여넣기 (Studio → 설명)
- 파일: `youtube_코스피_급락_설명란.txt` 그대로 복붙
- 필수 포함 3요소 체크:
  - [x] 첫 줄 “본 영상은 교육용 정보이며 투자 조언이 아닙니다”
  - [x] 원문 링크: https://n.news.naver.com/article/088/0001036043?type=breakingnews
  - [x] 타임스탬프 7개 (00:00~07:20) — 챕터 자동 생성됨
- 태그: 코스피, 팩트체크, 변동성, 금융교육, 재테크기초 (5개 이하, 자극 태그 금지)
- 카테고리: 교육 / 언어: 한국어 / 공개: 전체공개 + 댓글 허용

## 4. 수익화 자가진단 제출 (Studio → 수익 창출)
- 경로: Studio > 수익 창출 > 자가진단 설문
- 답변 예시 (복붙):
  - **제목/썸네일에 선정적 표현?** 아니오 — 사실 수치(3.52%) + “5단계 확인법”만 사용
  - **재사용 콘텐츠?** 아니오 — 직접 제작 그래프/체크리스트 70% 이상, 원문 인용 15% 이하, 나레이션 전체 자작
  - **금융 조언/허위정보?** 아니오 — “투자 권유 아님” 고지 3회, 가격 단정 없음, “내일 방향은 추측” 명시
  - **출처 표기?** 예 — 매일신문 2026.10.22 + 한국거래소 종가, 더보기란 링크, 영상 내 자막 “[출처]”
- 제출 전 체크: Studio > 콘텐츠 > 제한사항 없음 표시 확인 → 24시간 내 재심사 요청 가능
- 보관: `youtube_수익화_체크리스트.md`를 심사용 근거 메모로 첨부 (PDF 변환 권장)
