## 2. 5번 클릭으로 업로드 끝!

1. https://studio.youtube.com → **만들기 → 동영상 업로드**
2. `07_완성영상/코스피_완성영상_2분.mp4` 선택
3. **썸네일** → `01_썸네일/코스피_썸네일_1280x720.jpg` 선택
4. **설명** → `03_설명란/코스피_설명란.txt` 전체 복사→붙여넣기
5. **자막** → `02_자막/코스피_자막.srt` 업로드 (시간코드 있음 선택) → **게시**

끝! 찍을 필요 0, 편집 필요 0

---

## 3. 영상은 2분인데 괜찮나요?

- **네, 괜찮아요.** 유튜브는 2분 영상도 광고를 붙일 수 있어요. 구독자 500명 + 시청 3000시간 넘으면 수익화 신청이 됩니다.
- **8분으로 늘리고 싶으면?** CapCut 무료에서 1분 추가:
  1. https://www.capcut.com → 새 프로젝트 → `코스피_완성영상_2분.mp4` 넣기
  2. `05_차트/코스피_워크시트.png`를 끝에 60초 더 늘리기 (마우스로 늘리면 돼요)
  3. 배경 음악(무료) 살짝 깔기 → 내보내기 → 3분 완성! (유튜브는 3분도 좋아요)
  4. 8분이 꼭 필요하면 워크시트 장면을 5분으로 늘리고, 조용한 음악을 넣으세요 — 시청자가 적는 시간을 준다고 설명하면 자연스러워요.

> 💡 **팁:** 짧은 영상이 오히려 좋아요. 처음엔 2분으로 시작해서, 댓글에 “더 길게 해주세요”가 오면 8분 버전을 만들면 조회수가 더 잘 나와요.

## 4. 간단 편집만 하고 싶으면?

이미 완성 영상이 있지만, 조금 바꾸고 싶을 때:

1. CapCut → `07_완성영상` MP4 넣기
2. 자르고 싶은 부분 자르기 (가위 아이콘)
3. `05_차트` 그림을 원하는 곳에 추가 (드래그)
4. 글자 크기 바꾸고 싶으면? `01_썸네일` 사진 위에 텍스트를 새로 쓰기 (Pretendard 폰트 권장)
5. 자막(SRT)은 유튜브에 올린 뒤 자동 생성된 자막을 **수정**할 수도 있어요 — 오타가 있으면 Studio 자막 편집기에서 고치면 됩니다.

**음성만 바꾸고 싶으면?** `06_음성` MP3를 지우고, 자기 목소리로 `05_차트` 위에 녹음하면 돼요. CapCut → 오디오 → 녹음
