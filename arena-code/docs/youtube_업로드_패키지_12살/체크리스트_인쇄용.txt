영상 제목: _________________________

□ 1. 동영상 파일 (MP4) 만들었다
     → 대본 읽고 휴대폰으로 촬영

□ 2. 유튜브 Studio → 만들기 → 동영상 업로드

□ 3. 썸네일 넣었다
     → 01_썸네일/코스피_썸네일_1280x720.jpg

□ 4. 제목 붙여넣었다
     [팩트체크] 코스피 6일 새 3번 급락? 숫자 뒤에 숨은 5가지 확인법 | 투자 권유 아님

□ 5. 설명란 붙여넣었다
     → 03_설명란/코스피_설명란.txt 전체 복사

□ 6. 태그 5개 넣었다
     코스피, 팩트체크, 변동성, 금융교육, 재테크기초

□ 7. 자막 파일 올렸다
     → 02_자막/코스피_자막.srt (시간코드 있음)

□ 8. 수익화 체크 5개 모두 통과
     [x] 썸네일 직접 제작
     [x] 그래프 직접 제작
     [x] 기사 복붙 아님
     [x] 가격 단정 없음
     [x] 투자 권유 아님 고지

□ 9. 공개 → 게시 버튼 눌렀다!
