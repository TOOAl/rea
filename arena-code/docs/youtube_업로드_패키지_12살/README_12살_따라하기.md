3. **썸네일 넣기** → 01_썸네일 폴더 사진 선택
4. **설명란 붙여넣기** → 03_설명란 폴더 글 복사

## 1️⃣ 동영상 만들기 — 제일 쉬운 방법 2가지

### 방법 A: 휴대폰으로 직접 말하기 (추천! ⭐)

1. `04_대본` 폴더에서 `코스피_대본_읽기용.txt` 열기
2. 휴대폰 카메라 앱 켜기 → 가로로 들고 셀카 모드
3. 대본을 천천히 읽기 — 아래처럼 말하면 돼요:

> “6일 동안 코스피가 세 번이나 떨어졌어요. 어제는 올랐다가 오늘은 다시 떨어졌어요. 이게 정상일까요?”

4. 중간에 `05_차트` 폴더의 그림을 화면에 띄우기:
   - 컴퓨터로 그래프를 크게 띄워두고 촬영하거나
   - 카톡으로 내 휴대폰에 보내서 화면 캡처 후 편집 앱(CapCut 무료)에서 사진 넣기

**팁:** 완벽할 필요 없어요! 8분 안 채워도 5분만 해도 유튜브에 올라가요.

### 방법 B: 컴퓨터 화면 녹화 + 목소리

1. https://www.capcut.com (무료) 접속 → 새 프로젝트
2. `05_차트`의 SVG 파일을 넣고, 대본을 자막으로 붙여넣기
3. 마이크로 대본 읽기 → 저장(내보내기) → MP4 파일 완성

> 부모님께 물어볼 말: “유튜브에 올릴 교육 영상 만들려고 CapCut 써도 돼요?”

## 2️⃣ 유튜브에 올리기

1. https://studio.youtube.com 접속 (유튜브 앱에서는 오른쪽 아래 ‘+’ → 동영상 만들기)
2. 오른쪽 위 **‘만들기’ → ‘동영상 업로드’** 클릭
3. 방법 A/B로 만든 MP4 파일 선택

---

## 3️⃣ 썸네일 넣기 — 클릭을 만드는 사진!

1. 업로드 화면에서 **‘썸네일’ → ‘맞춤 썸네일 업로드’** 클릭
2. `01_썸네일` 폴더에서 고르기:
   - 코스피 영상 → `코스피_썸네일_1280x720.jpg`
   - 1929 영상 → `1929_썸네일_1280x720.jpg`
3. **확인:** 글자가 잘 보이나요? 휴대폰에서 작게 봐도 읽히면 성공!

> 왜 이 사진인가요?
> - AI가 글자를 쓴 게 아니라, 컴퓨터가 글자를 그려서 오타가 0개예요.
> - “팩트체크 / 투자 권유 아님”이 있어서 유튜브가 좋아해요.

## 4️⃣ 제목과 설명란 붙여넣기

### 제목 (복사해서 붙여넣기)

**코스피 영상:**
```
[팩트체크] 코스피 6일 새 3번 급락? 숫자 뒤에 숨은 5가지 확인법 | 투자 권유 아님
```

**1929 영상:**
```
[팩트체크] 1929 대공황 3일 전, 8명의 전문가는 이미 경고했다? | 투자 권유 아님
```

> ⚠️ 절대 쓰면 안 되는 제목: “대폭락 온다” “전액 매도하라” “내일 5000 간다” → 유튜브가 혼내요!

### 설명란 (복사해서 붙여넣기)

1. `03_설명란` 폴더에서 `코스피_설명란.txt` 열기
2. 전체 복사(Ctrl+A → Ctrl+C)
3. 유튜브 업로드 화면의 **‘설명’ 칸에 붙여넣기(Ctrl+V)**

설명란에는 이미 들어있어요:
- 원문 링크 (매일신문 기사)
- 시간 표시(00:00, 02:00...) → 자동으로 챕터가 생겨요!
- “투자 조언이 아닙니다” 문구 → 꼭 필요해요

### 태그 5개 (설명 아래 태그 칸에 넣기)

```
코스피, 팩트체크, 변동성, 금융교육, 재테크기초
```

## 5️⃣ 자막 넣기 — 이거 하면 조회수가 올라가요!

1. 업로드 화면에서 **‘자막’ → ‘한국어’ → ‘파일 업로드’** 클릭
2. **‘시간 코드 있음’** 선택
3. `02_자막` 폴더에서 고르기:
   - 코스피 영상 → `코스피_자막.srt`
   - 1929 영상 → `1929_자막.srt`
4. 업로드 → **저장**

> 왜 자막을 넣나요? 유튜브가 “이 영상은 글자를 다 썼네! 믿을 만하다!” 하고 더 많이 보여줘요.

## ✅ 업로드 전 마지막 체크 (수익화 체크)

유튜브는 “네가 만든 거 맞니?”를 검사해요. 이 체크를 통과해야 광고가 붙어요.

- [ ] 썸네일은 내가 만든 거? → **YES** (AI 배경 + 내가 그린 글자)
- [ ] 그래프는 내가 만든 거? → **YES** (`05_차트` SVG는 직접 만든 그림)
- [ ] 기사 글을 그대로 읽지 않았니? → **YES** (대본은 내 말로 다시 썼어요, 기사 문장은 2줄만 “매일신문에 따르면” 하고 말했어요)
- [ ] “내일 오른다/떨어진다” 단정했니? → **NO** (우리는 “모른다”고 말했어요)
- [ ] “투자하세요” 권했니? → **NO** (설명란·영상에 “투자 권유 아님” 3번 썼어요)

모두 체크되면 **‘공개’ → ‘게시’** 누르기!

## 🆘 자주 묻는 질문

**Q. 목소리가 부끄러워요.**
→ 괜찮아요! 자막 파일이 있어서 목소리 없이 음악+자막만 넣어도 영상 인정돼요. CapCut에서 “자동 음성” 무료 목소리 써도 돼요.

**Q. 8분을 꼭 채워야 하나요?**
→ 아니요! 5분이어도 괜찮아요. 8분 넘으면 중간 광고를 넣을 수 있어서 좋을 뿐이에요.

**Q. 수익화는 언제 되나요?**
→ 구독자 500명 + 시청시간 3000시간(또는 쇼츠 300만 조회)이 넘으면 신청할 수 있어요. 지금 올리는 건 그걸 위한 준비예요!

**Q. 부모님 동의가 필요해요?**
→ 14세 미만은 부모님 계정으로 올리거나, 부모님께 “교육용 영상 올릴게요” 하고 같이 ‘게시’ 버튼을 눌러주세요.
