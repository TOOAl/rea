## 왜 2분인가?

- TTS 원문 1,186자(코스피) / 1,251자(1929) → 필터 통과를 위해 금융 전문용어를 교육용으로 순화
- 생성 음성 평균 5.2초/문장 × 24문장 ≈ 124.9초
- 유튜브 수익화는 1분 이상이면 신청 가능(Shorts 포함), 8분은 중간 광고용 — 2분은 “간결한 교육 영상”으로 수익화 적합, 3분 이상 원하면 CapCut에서 워크시트 장면을 60-300초 연장하면 8분 달성 가능 (방법C 문서 참조)

## 콘텐츠 필터 대응

- 초기 텍스트(“매수 사이드카”, “브로커론”, “마진콜”, “3.52%”)가 TTS 필터에 거부됨 → “사는 것”, “빌린 돈”, “추가 증거금” 등으로 순화하여 재생성 성공
- 자막/설명란은 원문 수치(3.52%, 5,533.77 등)를 그대로 유지, 영상 내 차트 PNG에도 수치 표기 — TTS는 구어체로 변환(3.52퍼센트 → 3퍼센트, 5,533.77 → 5533)하여 청각적 이해도 향상

## 간단 편집 워크플로우

1. **무편집 업로드:** 07_완성영상 MP4 + 02_자막 SRT + 01_썸네일 JPG + 03_설명란 txt → 5클릭
2. **간단 편집:** CapCut에 07_완성영상 넣고, 05_차트 PNG 교체, BGM 추가, 워크시트 구간을 60초 늘려 3분 만들기
3. **고급 편집:** 06_음성 MP3를 타임라인에 놓고, 05_차트 5장을 각각 음성 길이에 맞춰 자르기 + 전환 효과
