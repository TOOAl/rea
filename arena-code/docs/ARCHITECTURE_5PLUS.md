# 5층+3.5게이트 아키텍처 — v2.23.0 (12살용 + 전문가용)

## 12살 설명 — 건물에 문을 하나 더 달았어요

기존 5층 건물(1기억→2설계→3창의→4천재→5의회)에 **3.5층 문**을 달았어요. 1층엔 안내원 3명이 새로 와서 “어디에 뭐 있는지”를 먼저 알려주고, 2층엔 역사·경영·공학 선생님 3명이 설계도를 더 튼튼하게 만들어요.

```
1층 기억도서관 8명 — 지도·언어·맥락 3천재가 “재료가 어디 있는지” 안내
  ↓
2층 설계사무실 6명 — 역사·경영·공학 전략가가 목표·가정·제약을 문서로
  ↓
3층 창의공방 3명 — 야생 아이디어 3개 + 비판 3문항 + 통계 심사
  ↓
3.5층 게이트 — 30명 천재 중 과제에 꼭 필요한 7명 + 와일드카드 1명 = 8명 투표
  ├─ 6/8 이상 O → 4층으로 통과
  └─ 5/8 이하 X → 반려 사유서와 함께 2층/3층으로 돌려보냄 (최대 2번, 그 다음엔 5층으로)
  ↓
4층 토론정원 — 통과된 안을 다양한 시선으로 토론해 최고안 1개 + 대안 2개
  ↓
5층 의회 — 투표·합의

엘리베이터: 1→2→3→3.5→4→5, 단 한 번. 3.5층에서만 필요하면 아래층으로 “다시 고쳐와!” 호출.
```

## 왜 이렇게 바꿨나 (첨부 4개 분석 요약)

* **01 역사전략가:** 목표부터 고정, 정보품질 점검, 보급·철수조건, 중단기준 — 2층에 배치
* **02 경영전략가:** 드러커 3~5개 목표, TPS 이상 시 중단, 사이먼 가역성, OODA 짧은 주기 — 2층 6리듬으로
* **03 공학설계자:** 레오나르도 관찰-실험-검증 라벨, 라이트 맥락통합, NASA 추적성 — 2층 성숙도 6문항으로
* **04 통합분석:** 7단계 프로세스(문제정의→가정분리→제약→대안→프로토→실행→피드백) + AI 5계층(A입력·B증거·C엔진·D승인·E감사) — 전체 뼈대

모두 “천재 한 명 흉내”가 아니라 **사람이 감독하는 학습 체계**를 강조하므로, 게이트는 “막는 문”이 아니라 “학습시키는 문”입니다.

## 1층 3천재 상세

| 천재 | 하는 일 | 산출물 |
|------|---------|--------|
| 기억 천재 (Archivist) | 어디에 어떤 기억/실패/모순이 있는지 지도 | 저장 위치 맵 + 필요 서랍 3개 |
| 언어 천재 (Interpreter) | 프로젝트 문장의 숨은 뜻·모호함·전제 파악 | 의도·모호점·추천 질문 1개 |
| 맥락 천재 (Synthesizer) | 전체 기억을 훑어 필요한 데이터만 선별 | 맥락 요약 1줄 + 필수 데이터 좌표 |

→ 2층이 설계도를 그리기 전에 재료가 준비됨.

## 2층 3전략가 상세

* **역사 전략가:** 5원칙(목표고정·정보점검·병목집중·중단기준·학습장치)
* **경영 전략가:** 6리듬(목표·흐름·결정·실행·문제대응·검토) + 가드레일(지표조작·편향 점검)
* **공학 설계자:** 6문항(문제정의·요구사항·대안2개·인터페이스·검증·운영) + 추적성 그래프

## 3.5층 게이트 상세 — 필요 기반 7+1

* **선발:** 과제 벡터(6차원: 구조·통합·시각·형식·실용·변형)와 30명 프로필 벡터의 코사인 유사도 → 상위 7명 + 최하위 1명(와일드카드). 결정적(동점→id순), 재현 가능.
* **검증 3문항:** 근거 있음? 실현 가능? 윤리 문제 없음? (04의 인간승인·감사 원칙)
* **통과:** 6/8 이상 O → 4층 토론. 5/8 이하 → 반려 사유서와 함께 아래층 회송, 최대 2회 후 5층 에스컬레이션.
* **효과:** 4층은 평가가 아니라 “종합 토론”에 집중.

## 4층 새 역할 — 토론·종합

기존 “각자 자기 공식 적용”에서 → “같은 안을 서로 다른 시선으로 토론해 최고안 도출”로 변경. 투표 후 5층에 1순위+대안2개 전달.
