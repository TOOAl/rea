# 🧠 뇌과학 학습 순서 — REA 5층으로 외우는 법

> **핵심 약속**: 뇌는 **“많이 보는 게 아니라 꺼내보는”** 것으로 기억한다. 이 문서는 5층 REA를 공부 기계로 바꾼 설계도다.

## 1. 뇌가 좋아하는 5가지 원칙 (12살 설명)

| 원칙 | 12살 비유 | REA 층 | 공부 행동 |
|------|-----------|--------|-----------|
| **간격 반복(Spaced)** | 과자 나눠 먹기. 한 번에 10개보다 매일 2개씩 | 1층 필터 | Anki 1일·3일·7일·30일 복습 |
| **인출 연습(Retrieval)** | 문제집 덮고 답 말하기. 보기 전에 꺼내기 | 3층 천재 | 백지테스트(빈 종이에 쓰기) |
| **교차 학습(Interleaved)** | 수학·국어·영어 번갈아 풀기 | 2층 설계사무실 | 회계·민법·경제를 하루에 섞기 |
| **이중 코딩(Dual Coding)** | 글 + 그림 같이 보기. 노래 가사+뮤비 | 5층 시각 | 표·지도·그래프 손으로 그리기 |
| **정교화(Elaboration)** | 동생에게 설명하기. 왜 그런지 말하기 | 4층 통합 | “왜 2014도191은 유죄?” 1분 설명 |

→ 이 5개를 **매일 30분씩** 하면 3시간 벙벼치기보다 기억이 2배 남는다.

## 2. REA 5층을 공부 5단계로 바꾸기

### 1층 필터 — “모른다” 표시
- 공부 중 추측 금지. 모르면 **?** 표시. 매일 ?를 줄이는 게 목표.
- 행동: 오답노트에 **“추측(근거 없음) / 해석(근거 반쪽) / 사실(조문·판례)”** 3칸으로 나누기 — 2차 논술에서 바로 쓰임.

### 2층 설계사무실 — 4명의 전략가
| 전략가 | 원래 천재 | 공부 역할 | 중단 기준 |
|--------|-----------|----------|-----------|
| 목표 고정 | 클라우제비츠 | 동차=4월 1차 60점·7월 2차 40점 방어 | 주간 모의고사 평균 55점 미달 시 계획 수정 |
| 정보 품질 | 손자 | 조문·판례 원문 1순위, 요약집 2순위 | 출처 없는 요약은 버리기 |
| 용량·병목 | 나폴레옹 | 회계학=병목. 하루 40분만, 매일 조금씩 | 회계 30점 이하 2주 지속 → 인강 추가 |
| OODA | 파일럿 | 즉흥 변경 금지. 관찰-판단-결정-행동을 주간 단위로 | 주간 회고 일요일 20분 고정 |

### 3층 천재 36인 — 어려운 과목을 쉽게
- **가우스(수학)**: 회계·경제 계산은 **공식 10개**만 외우면 70%. 감가상각·재고·IS-LM 3개를 매일 손풀기.
- **폰노이만(시스템)**: 관계법규 10법은 **트리**로. 국토계획법→용도지역→건폐율→건축법 흐름.
- **베토벤(리듬)**: 민법 판례 15개는 **이야기+리듬**으로. “삼정KPMG 1.5억 유죄~” 노래처럼.
- **구텐베르크(인쇄)**: 2차 논술은 **틀**로 찍어내기. 서론-본론(3단계)-결론-판례번호 1개.

### 3.5층 게이트 — 6/8 통과해야 암기 끝
- 암기 기준: **6명에게 설명해 6명이 이해하면 통과**. 가족·스터디·Council 봇 6명에 설명하기.
- 실패하면 1일 후 재시도(간격 반복). 2회 실패 시 그림(지도로 다시).

### 4층 통합·5층 시각 — Council + 그림
- **Council 8명 토론**: 1차 민법 문제를 경제·회계 시각으로 다시 보기(교차 학습).
- **시각 두뇌**: 부동산학원론·경제 그래프는 **손으로 3번 그리기**. 뇌는 손을 기억한다.

## 3. 과목 순서 — “쉬운 것부터 병목까지” (12개월)

**뇌과학 순서 원칙**: `자신감(부동산학) → 뼈대(민법·경제) → 벽(회계·법규) → 통합(2차 이론·실무)`

| 단계 | 기간 | 과목 | REA 층 | 뇌과학 이유 |
|------|------|------|--------|-------------|
| **1. 씨앗** | 1~2개월 | 부동산학원론 | 1→2층 | 과락 12%로 가장 쉬움. 성취감으로 도파민 확보 |
| **2. 뿌리** | 3~4개월 | 민법(총칙·물권) | 3층 가우스 | 판례 이야기로 기억. 매일 10판례 인출 |
| **3. 기둥** | 5~6개월 | 경제학원론 | 3층 폰노이만 | 그래프 이중코딩. 계산은 매일 20분씩 |
| **4. 벽** | 7~9개월 | 회계학 + 관계법규 | 2층 병목 | 가장 어려운 병목. 교차+간격으로 조금씩. 40점 방어 |
| **5. 지붕** | 10~12개월 | 2차 이론·실무·보상법규 | 4·5층 | 1차 지식이 2차와 연결(이론=원리, 실무=계산). 통합 학습 |

→ **금지**: 회계부터 시작 X (좌절), 법규 10개를 한 번에 X (과부하). 뇌는 작은 성공을 좋아한다.

## 4. 하루 3시간 뇌과학 루틴 (직장인·학생 공용)

```
[0-10분] 어제꺼 꺼내기 (백지테스트) — 간격 반복
  부동산학 5문제·민법 판례 3개를 보기 전에 답하기

[10-40분] 새 것 30% (정교화)
  오늘 용어 5개 → 12살 설명으로 말하기 → 녹음

[40-70분] 계산 20% (교차)
  회계 5문제 + 경제 5문제를 섞어 풀기

[70-90분] 판례 20% (이중코딩)
  판례 2개 → 사실-판결-포인트 표 그리기

[90-100분] 내일 꺼내기 예약 (게이트)
  오늘 10개 중 6개 이상 맞으면 통과, 아니면 내일 다시

[주말 60분] 모의 Council — 8명 역할로 문제 토론
  “회계사는 왜 토지감정 못 하나?” 8명이 찬반 → 결론 1줄
```

**수면**: 12시 전 취침, 7시간. 뇌는 자면서 정리한다.

## 5. 동차 합격의 뇌과학 함정 3개

1. **확신의 함정**: “이번엔 쉽게 낼 거야” 추측 금지. 2026 1차 18.22% 폭락처럼 매년 난도 다르다 → 1층 필터로 차단.
2. **병목 무시**: 회계 40점 넘으면 평균이 10점 오른다. 나폴레옹 “병목을 뚫어야 전체가 간다”.
3. **지각된 피로**: 2차 실무 과락 71%는 “다 안다” 착각 때문. 백지테스트로 매번 확인.
