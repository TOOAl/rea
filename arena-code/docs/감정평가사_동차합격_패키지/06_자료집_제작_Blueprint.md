# 🛠️ 자료집 제작 Blueprint — REA로 뽑는 법 (개발자·수험생 공용)

> 이 문서는 `TOOAI/rea` main을 **감정평가사 공부 기계**로 쓰는 매뉴얼. 코드 없이도 개념을 따라 하면 된다.

## 1. REA 5층을 공부 파이프라인으로

```
[입력] “민법 유치권 판례 5개 요약해줘”
  ↓
1층 필터 — 3천재가 “모르는 건 모른다” 체크 (기억 환각 차단)
  ├─ memoryGenius: “2014도191은 회계사 감정 금지” 기억 검증
  ├─ 오류탐지 천재: “유치권=점유=견련성 빠짐” 경고
  └─ 창의 천재: “12살 비유로 풀자” 제안
  ↓
2층 설계사무실 — strategist 3명이 계획
  ├─ 목표 고정(클라우제비츠): “동차 40점 방어용 1장 요약”
  ├─ 정보품질(손자): “원문=대법원 판결문 1순위”
  └─ 병목(Napoleon): “5개 판례를 1장으로 압축해야 기억에 남는다”
  ↓
3층 천재 36인 — 병렬 생성
  - 가우스: “표로 정리” / 폰노이만: “트리로 분류” / 베토벤: “리듬으로 외우기”
  ↓
3.5층 게이트 — 6/8 투표로 검증
  - “유치권 성립요건 3개가 모두 있는가? 판례 번호가 맞는가? 12살 설명이 틀리지 않았는가?”
  ↓
4층 Council — 8명 토론으로 통합
  ↓
5층 최종 — 12살 용어집 1장 + Anki 카드 10개 + 백지테스트 5문제로 출력
```

→ 이 흐름을 **1주 1자료집**으로 반복하면 52주치 자료집이 쌓인다.

## 2. 바로 쓰는 프롬프트 3개

### 프롬프트 A: 용어 12살 변환
```
너는 REA 1층 filter다. 다음 용어를 12살이 이해하게 “과자·게임 비유”로 풀어줘.
조건: 사실/해석/추측을 나누고, 추측은 “모른다”고 표시. 출처는 조문·판례 번호.
용어: [유치권]
출력: 3줄(정의 1줄+비유 1줄+시험 포인트 1줄)
```

### 프롬프트 B: 판례 3줄 요약
```
너는 3층 천재다. 판례 [2014도191]을
1) 사실(무슨 일) 2) 판결(이유 1줄) 3) 시험에 나오는 OX 1개
로 요약하라. 게이트 기준: 6/8이 이해해야 통과.
```

### 프롬프트 C: 주간 모의 생성
```
너는 2층 strategist다. 이번 주는 회계학 7주차다.
조건: 40문제 중 과락률 46%인 회계학을 40점 방어용으로,
계산 50%+이론 30%+판례 20%로 섞어 20문제 모의고사를 만들어라.
출력: 문제-정답-해설-오답노트용 ?칸 4열
```

## 3. 자료집 자동화 — harness2 6단계

| Harness2 단계 | 감정평가사 적용 | REA 층 |
|---------------|----------------|--------|
| **Goal** | “동차 평균 60점, 과락 0” 고정 | 2층 |
| **Spec** | “민법 40문제 중 판례 36문제” 스펙 정의 | 2층 |
| **Planner** | 52주 로드맵 쪼개기 | 2층 |
| **TDD** | 백지테스트 5문제로 먼저 만들기 | 3층 |
| **Interrogate** | Gate 6/8 검증 — 틀린 조문·번호 잡기 | 3.5층 |
| **Verify** | 모의 40점/60점 Gate 통과 확인 | 5층 |

→ `arena-code/src/harness2/`를 그대로 쓰면, 매주 자료집을 **테스트→검증**으로 뽑을 수 있다.

## 4. Anki·백지테스트 템플릿

### Anki 카드 (앞/뒤)
```
앞: 유치권이 생기는 3가지 조건은?
뒤: 1) 내 손에 쥐고 있음(점유) 2) 돈 안 준 것과 연결(견련성) 3) 물건 돌려주기 전
    → 12살: “돈 안 주면 과자 안 돌려줘”
```

### 백지테스트 (매일 10분)
```
1. 유치권 3요건 쓰기: ______ ______ ______
2. 2014도191 결론 1줄: ____________________
3. 감가상각 공식 1개: ____________________
```

## 5. 시각 자료 규칙 — 5층 시각 두뇌

- **표 1개 > 글 10줄**: 모든 판례는 표로.
- **손그림 3번**: 경제 IS-LM, 부동산 3방식 트리는 손으로 3번.
- **색 3가지**: 사실=파랑, 해석=노랑, 추측=빨강(REA 1층 색 그대로).
