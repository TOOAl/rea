# 🏠 감정평가사 동차합격 패키지 — 12살도 이해하는 개요

> **감정평가사** = 땅·건물·공장 같은 것들의 **제값**을 정하는 사람. 병원 의사가 사람 건강을 진단하듯, 감정평가사는 **부동산 건강(가격)**을 진단합니다.

## 시험이 왜 2번으로 나눠있을까?

**놀이기구 비유**로 이해해 보세요.

- **1차 시험(객관식 5지선다)**: 놀이공원 입장권 검사. 5개 중 1개 정답 고르기. 5과목 × 40문제 = 200문제. 40점 넘고 평균 60점 넘으면 통과.
- **2차 시험(논술 4문제×3과목)**: 놀이기구 직접 운전하기. 서술 + 계산으로 “왜 이 가격인지 설명”해야 합니다. 3과목 각각 100분, 한 과목이라도 40점 미만이면 떨어집니다.

**동차 합격** = 1차·2차를 **같은 해에 한 번에** 붙는 것. 1차 합격 후 다음 해 2차만 볼 수도 있지만, 동차는 4월 1차 → 7월 2차 → 9월 최종합격을 한 번에 노리는 코스. 빠르지만 어려워요(최종 합격률 3~6%).

### 왜 이 패키지를 만드나?

TOOAI **REA 5층**을 공부 기계로 썼습니다.

- **1층 필터**: “모르는 건 모른다” 표시 — 추측 금지
- **2층 설계사무실**: 목표(동차)·정보품질·병목(회계학)·중단기준(OODA) 잡기
- **3층 천재 36인**: 클라우제비츠(목표 고정), 손자(정보), 나폴레옹(용량) 등 전략 적용
- **4층 통합·3.5층 게이트**: Council 8명 토론 + Gate 6/8 통과로 검증
- **5층 최종**: 수익화 아닌 **합격**
