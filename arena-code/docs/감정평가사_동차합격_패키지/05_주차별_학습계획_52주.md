## 동차 합격의 비밀 — “1차가 2차를 먹여살린다”

- 부동산학 60점 → 2차 이론·실무 20% 이해
- 민법 판례 15개 → 2차 보상법규 서술 근거
- 관계법규 10법 → 2차 보상법규 50% 그대로
- 회계 40점 → 2차 실무 계산 감각

→ 1차를 버리고 2차만 하면 둘 다 떨어진다. **1차를 무기로 2차를 친다.**
