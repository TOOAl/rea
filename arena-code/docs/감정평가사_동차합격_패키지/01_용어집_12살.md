# 📚 감정평가사 핵심 용어집 — 12살 버전 (60개)

> **읽는 법**: 왼쪽은 시험 단어, 가운데는 12살 설명(과자·게임 비유), 오른쪽은 어느 과목에서 나오는지.

## A. 부동산학원론 · 감정평가이론 (집값 원리)

| 용어 | 12살 설명 | 시험 포인트 |
|------|-----------|-------------|
| **시가/적정가격** | 오늘 시장에서 실제로 거래될 것 같은 값. 중고폰 **시세**처럼. | 이론 단골. 시가주의 원칙(상증세법 60조)과 연결 |
| **감정평가 3방식** | 집값 재는 자 3개: **비용성**(얼마 들었나=원가), **시장성**(옆집 얼마에 팔렸나=비교), **수익성**(월세로 얼마 버나) | 2차 이론·실무 모두. 3방식 조정 필수 |
| **원가방식** | 새로 짓는데 얼마+땅값-낡은 만큼. 레고 부품을 새로 사서 조립비 빼는 느낌 | 재조달원가, 감가수정 |
| **거래사례비교법** | 옆집·앞집 실거래가 모아 내 집 값 추정. 당근마켓 시세 보기 | 비교사례 선정 3요건: 시점·지역·개별요인 보정 |
| **수익환원법** | 월세 100만원×12개월 ÷ 이자율. 과자가 매년 얼마 버는지로 가게 값 매기기 | 순수익, 환원율, DCF |
| **임료(임대료) 감정** | 월세 적정선 찾기 | 실무: 적산법·비교법·수익분석법 |
| **최유효이용** | 그 땅에 아파트? 주차장? 중 가장 돈 되는 쓰임새 | 이론 1순위. “가장 높은 가치” |
| **부동산 특성** | 부동성(못 옮김), 개별성(세상에 같은 땅 없음), 영속성 | 부동산학 총론 빈출 |
| **외부효과** | 옆에 공원 생기면 내 집값↑, 쓰레기장 생기면↓ | 경제학과 연결 |
| **지가공시** | 나라가 매긴 땅값 기준표. 시험 점수표 같은 존재 | 관계법규·보상법규 모두 |
| **개발이익** | 논에 아파트 지으면 생기는 추가 이익. 레벨업 보너스 | 개발부담금과 연결 |

## B. 경제학원론 (돈의 흐름)

| 용어 | 12살 설명 | 포인트 |
|------|-----------|--------|
| **수요·공급** | 사고 싶은 사람 vs 팔고 싶은 사람. 줄다리기 | 수요곡선 이동 vs 수요량 이동 구분 |
| **탄력성** | 가격 10% 오를 때 수요가 얼마나 줄까? 고무줄처럼 | 부동산은 비탄력적 |
| **GDP/물가** | 나라 전체 과자 생산량 vs 과자값 | 거시 빈출, 인플레이션·디플레이션 |
| **화폐수량설** | 돈이 많이 풀리면 과자값 오른다 | MV=PY |
| **IS-LM** | 돈 시장과 물건 시장이 만나는 점 | 1차 경제학 단골 그래프 |
| **외부성·공공재** | 공원·도로는 모두가 쓰지만 돈 안 냄. 정부가 나서야 함 | 시장실패 → 정부 개입 논리 |
| **조세 전가** | 세금 내는 사람과 실제 부담하는 사람이 다름. 풍선 누르기 | 종량세·종가세 |

## C. 회계학 (장부)

| 용어 | 12살 설명 | 포인트 |
|------|-----------|--------|
| **자산·부채·자본** | 내 것(자산) = 빚(부채) + 내 돈(자본). 용돈 기입장 | 재무상태표 기본식 |
| **수익·비용** | 번 돈과 쓴 돈. 월급-용돈 = 남는 돈 | 손익계산서 |
| **감가상각** | 컴퓨터를 5년 쓰면 매년 20% 낡음 처리. 헌 운동화 값 깎기 | 정액법·정률법 계산 빈출 |
| **현금흐름표** | 진짜 현금이 어디서 들어오고 나갔나. 지갑 출입 기록 | 영업·투자·재무 3구분 |
| **재고자산 평가** | 과자 재고는 얼마로 잡을까? FIFO/LIFO, 저가법 | 1차 회계학 계산 핵심 |
| **자본적지출 vs 수익적지출** | 집 수리: 지붕 교체(자산↑) vs 페인트칠(비용) | 구분 문제 매년 출제 |

## D. 민법 (약속·소유)

| 용어 | 12살 설명 | 포인트 |
|------|-----------|--------|
| **법률행위·의사표시** | “사겠다” “팔겠다” 말하는 순간 약속 시작 | 통정허위표시, 착오·사기·강박 |
| **대리** | 친구가 내 대신 과자 사오기. 권한 없으면 무효 | 무권대리, 표현대리(믿게 만든 책임) |
| **소멸시효** | 오래 가만히 있으면 권리 사라짐. 숙제 안 내면 0점 | 10년 vs 5년 vs 3년 |
| **물권·채권** | 물권=내가 직접 지배(내 집), 채권=남에게 요구(이행해줘) | 물권의 배타성 |
| **점유·소유** | 점유=쥐고 있음, 소유=법적 주인. 도둑도 점유는 한다 | 점유보호 |
| **저당권·전세권** | 저당=못 갚으면 집 팔아 갚기, 전세=돈 맡기고 집 빌림 | 물권편 40% 차지 |
| **유치권·질권** | 유치=돈 안 주면 물건 안 돌려줌, 질=담보 맡김 | 1차 민법 판례 60% 이상 |
| **등기** | 집 주인이 누구인지 나라 장부에 적기. 게임 랭킹 등록 | 등기의 공시력 vs 공신력(믿고 샀어도 보호 안 됨) |

## E. 감정평가관계법규·보상법규 (법 10개)

| 법 | 12살 설명 | 출제 특징 |
|----|-----------|----------|
| **감정평가법** | 감정평가사 자격·의무·징계 규칙. 선수 자격증 | 자격·업무범위·성실의무·과징금(대법원 2020두41689) |
| **부동산공시법** | 공시지가·공시가격 만드는 법. 성적표 만드는 법 | 표준지·개별지, 공시절차 빈출 |
| **국토계획법** | 어디에 집·공장·공원 지을지 정하는 법. 도시 레고 설명서 | 용도지역·지구·구역, 개발행위허가 |
| **건축법** | 건물 어떻게 지어야 하는지. 레고 조립 설명서 | 건폐율·용적률·건축허가 |
| **공간정보관리법(지적)** | 땅의 주민등록. 필지·지목·면적 | 지적공부·측량 |
| **국유재산법** | 나라 땅 빌리고 사고 파는 법 | 국유재산 종류·관리 |
| **도시정비법** | 오래된 동네 다시 짓는 법. 재개발·재건축 | 추진위·조합·관리처분 |
| **부동산등기법** | 등기부에 어떻게 적는지 | 등기 종류·효력 |
| **동산채권담보법** | 기계·재고도 담보로 맡길 수 있다. 게임 아이템 담보 | 설정·등기 |
| **공익사업보상법(토지보상법)** | 나라가 땅 뺏을 때 얼마 줘야 하는지. 강제 이사 보상 | **2차 보상법규의 50%**. 생활보상·영업보상·잔여지 |
| **세법 간접** | 취득세·재산세·양도세는 감정과 연결 | 취득 시세 적용 판례(2025두35499) |

## F. 감정평가실무·이론 심화 (2차)

| 용어 | 12살 설명 | 2차 연결 |
|------|-----------|----------|
| **감가수정 3방법** | 내용연수·관찰·분해. 낡은 정도 재는 자 | 원가방식 핵심 |
| **지역·개별요인 비교** | 옆 동네 vs 내 땅, 넓이·모양·도로 차이 | 비교법 보정 |
| **수익비용 대응** | 순운영소득(NOI)=총수익-총비용. 월세통장 잔액 | DCF, 직접환원법 |
| **할인현금흐름(DCF)** | 미래 월세를 오늘 값으로 당겨오기. 타임머신 계산 | 10년치 현금흐름 할인 |
| **보상평가 원칙** | 뺏기기 전날 값으로, 개발이익 빼고. 어제 시세로 정산 | 2차 보상법규 서술형 단골 |
| **성실·공정 의무** | 거짓·부당 감정 금지. 심판이 편들면 안 됨 | 법 37조, 2024두54348(꼬마빌딩) |
