# 🤖 Arena Code 기능 설명서 — 12살도 이해하는 버전

> **어려운 단어는 쓰지 않았습니다!**
> 초등학생도 이해할 수 있도록 일상적인 비유로 설명합니다.

---

## 🌟 Arena Code는 뭔가요?

### 한 문장으로 말하면

> **"코딩을 도와주는 로봇 비서"** 입니다.
> 말로 시키면, 스스로 파일을 읽고 고치고 실행합니다.

### 비유로 이해하기

Arena Code를 **레고 조립 로봇**이라고 상상해보세요:

| 로봇의 부위 | Arena Code에서 | 역할 |
|------------|---------------|------|
| 🧠 두뇌 | LLM (Gemini, ChatGPT 등) | 생각하고 계획 세우기 |
| 🦾 손 | 도구 (Tools) | 파일 읽기/쓰기, 명령 실행 |
| 📖 규칙책 | AGENT.md + 권한 시스템 | 무엇을 해도 되는지 규칙 |
| 👂 귀 | 터미널 입력 | 사람의 말 듣기 |
| 👄 입 | 터미널 출력 | 사람에게 대답하기 |

사람이 **"이 레고 성을 고쳐줘"** 라고 말하면:
1. 🧠 두뇌가 생각: "어디가 고장났지? 먼저 살펴봐야겠다"
2. 🦾 손이 움직임: 파일을 읽고, 문제를 찾고, 고치고, 테스트
3. 👄 입이 보고: "여기 고쳤어요! 확인해보세요"

이 과정을 **자동으로 반복**하는 것이 Arena Code입니다!

## 🧠 두뇌 — 6가지 중 하나를 고를 수 있어요

두뇌는 로봇의 생각하는 부분입니다. Arena Code는 **6가지 두뇌** 중 하나를 쓸 수 있습니다:

### 두뇌 목록 (비유: 과외 선생님)

| 두뇌 이름 | 비유 | 가격 | 특징 |
|-----------|------|------|------|
| **Gemini** | 친절한 구글 선생님 | 🆓 무료 | 1M 토큰(책 1000권 분량), 가장 관대 |
| **OpenRouter** | 여러 선생님이 모인 학원 | 🆓 무료 | 모델이 가장 많음 |
| **Groq** | 번개처럼 빠른 선생님 | 🆓 무료 | 속도가 500토큰/초로 가장 빠름 |
| **Ollama** | 집에서 공부하는 선생님 | 🆓 무료 | 인터넷 없이도 됨, 비밀 유지 |
| **Arena Agent** | Arena 전용 선생님 | 🆓 크레딧 내 | Arena 안에서 동작 |
| **Anthropic Claude** | 원래 Claude Code 선생님 | 💰 유료 | 가장 똑똑하지만 돈이 듦 |

> 💡 **모두 같은 손(도구)을 씁니다!** 두뇌만 바뀌고, 하는 일은 같습니다.
> 그래서 공짜 두뇌로도 충분히 쓸 수 있습니다!

### 두뇌 바꾸는 방법 (1초!)

```bash
# Gemini 선생님으로
node dist/cli.js --provider gemini -p "버그 찾아줘"

# Groq 선생님으로 (빠르게)
node dist/cli.js --provider groq -p "버그 찾아줘"

# Ollama 선생님으로 (오프라인)
node dist/cli.js --provider ollama -p "버그 찾아줘"
```

환경변수로도 가능:
```bash
ARENA_PROVIDER=gemini node dist/cli.js
```

## 🦾 손 — 8가지 도구를 쓸 수 있어요

로봇의 손은 실제로 파일을 만지고 명령을 실행하는 부분입니다.
Claude Code와 똑같은 8가지 손을 가지고 있습니다:

### 📖 Read — 파일 읽기

> **비유: 책 읽기**

파일 내용을 읽습니다.

```
사람: "math.js 파일이 뭐하는 파일인지 알려줘"
로봇: [Read 도구로 math.js 읽기] → "이 파일은 덧셈, 나눗셈, 팩토리얼 기능을 하는 파일이에요"
```

- 한 번에 2000줄까지 읽을 수 있습니다
- 이미지, PDF도 읽을 수 있습니다 (내용을 텍스트로 변환)

### ✍️ Write — 새 파일 만들기

> **비유: 새 노트에 글쓰기**

새 파일을 만들거나, 기존 파일을 완전히 덮어씁니다.

```
사람: "hello.js 파일을 만들고 인사하는 코드를 넣어줘"
로봇: [Write 도구로 hello.js 생성] → "만들었어요! 확인해보세요"
```

### 🔧 Edit — 파일 일부 고치기

> **비유: 연필로 틀린 글자만 지우고 고치기**

파일의 일부만 정확히 찾아서 고칩니다. Write보다 안전합니다.

```
사람: "divide 함수에 0으로 나누는 경우 에러 처리를 추가해줘"
로봇: [Edit 도구로 divide 부분만 교체] → "고쳤어요!"
```

- `old_string`이 정확히 일치해야 합니다 (공백까지!)
- 여러 곳에 같은 내용이 있으면 `replace_all`을 사용합니다

### 💻 Bash — 컴퓨터 명령 실행

> **비유: 만능 리모컨**

컴퓨터가 할 수 있는 모든 명령을 실행합니다.

```
사람: "테스트를 실행해봐"
로봇: [Bash 도구로 "npm test" 실행] → "테스트 결과 3개 성공, 1개 실패입니다"

사람: "git 상태 보여줘"
로봇: [Bash 도구로 "git status" 실행] → "변경된 파일 2개..."
```

- `git`, `npm`, `python`, `ls` 등 모든 명령 가능
- 위험한 명령(`rm -rf /`, `sudo` 등)은 자동으로 차단됩니다!

### 🔍 Glob — 파일 찾기

> **비유: 보물 찾기**

파일 이름 패턴으로 파일을 찾습니다.

```
사람: "프로젝트에 TypeScript 파일이 몇 개 있어?"
로봇: [Glob 도구로 "**/*.ts" 검색] → "15개 파일이 있습니다: ..."
```

- `**/*.ts` — 모든 TypeScript 파일
- `src/**/*.js` — src 폴더의 모든 JavaScript 파일

### 🔎 Grep — 내용으로 찾기

> **비유: 책에서 특정 단어 찾기**

파일 내용에서 특정 단어나 패턴을 찾습니다.

```
사람: "TODO라고 적힌 곳을 찾아줘"
로봇: [Grep 도구로 "TODO" 검색] → "3군데에서 찾았어요: ..."
```

- `ripgrep`이라는 빠른 도구를 사용합니다 (Claude Code도 동일)
- 정규식(패턴) 검색도 가능합니다

### 📋 TodoWrite — 할 일 목록

> **비유: 숙제 체크리스트**

복잡한 작업을 단계별로 나누고 진행 상황을 추적합니다.

```
사람: "쇼핑몰 웹사이트를 만들어줘"

로봇: [TodoWrite로 계획 세우기]
  → ○ 상품 목록 페이지 만들기
  → ○ 장바구니 기능 만들기
  → ○ 결제 페이지 만들기
  
  [하나씩 진행하며 상태 업데이트]
  → ✓ 상품 목록 페이지 만들기 (완료)
  → → 장바구니 기능 만들기 (진행 중)
  → ○ 결제 페이지 만들기 (대기)
```

> 💡 복잡한 작업 전에 **반드시** TodoWrite를 쓰는 것이 좋습니다!
> 로봇이 계획을 세우고, 어디까지 했는지 잊지 않습니다.

### 🌐 WebFetch — 인터넷에서 가져오기

> **비유: 도서관에서 책 빌려오기**

인터넷 주소를 입력하면 내용을 가져와서 텍스트로 변환합니다.

```
사람: "React 공식 문서를 가져와서 요약해줘"
로봇: [WebFetch로 react.dev 접속] → "React는 UI 라이브러리입니다..."
```

## 🛡️ 규칙 — 로봇이 함부로 못 하게 막기

로봇이 중요한 파일을 망가뜨리면 안 되니까, **규칙**이 있습니다:

### 권한 시스템 (3단계)

| 단계 | 의미 | 비유 |
|------|------|------|
| ✅ **allow** | 바로 허용 | "연필로 쓰기 — 마음대로 해" |
| ❓ **ask** | 사람에게 물어보기 | "가위로 자르기 — 해도 될까요?" |
| ⛔ **deny** | 무조건 차단 | "불장난 — 절대 안 돼!" |

### 기본 규칙 예시

```
allow (바로 허용):
  Read(*), Glob(*), Grep(*)           → 읽기/찾기는 안전하니까 허용
  Bash(git status), Bash(npm test)    → 확인하는 명령은 허용

ask (물어보기):
  Write(*), Edit(*)                    → 파일 쓰기/고치기는 물어보기
  Bash(*)                              → 명령 실행은 물어보기

deny (차단):
  Bash(rm -rf /*)                      → 전체 삭제는 절대 금지
  Read(.env)                           → 비밀번호 파일은 못 읽음
```

### 규칙 바꾸는 방법

`.arena-code/settings.json` 파일을 수정하면 됩니다:

```json
{
  "permissions": {
    "allow": ["Read(*)", "Glob(*)"],
    "ask": ["Bash(*)", "Write(*)"],
    "deny": ["Bash(rm -rf /*)", "Read(.env)"]
  }
}
```

> 💡 `*`는 "모든 것"을 의미합니다. `Read(*)`는 "모든 파일 읽기"라는 뜻!

## 📖 기억 — AGENT.md

로봇은 **AGENT.md**라는 파일을 기억합니다. 프로젝트 규칙을 적어두는 곳입니다.

### AGENT.md가 뭔가요?

> **비유: 가정통신문**

선생님이 학생에게 "우리 반 규칙"을 알려주는 것처럼, AGENT.md는 로봇에게 "이 프로젝트 규칙"을 알려줍니다.

```markdown
# AGENT.md 예시

## 프로젝트 규칙
- 모든 함수는 설명(JSDoc)을 붙여주세요
- 커밋 메시지는 "feat: ..." 형식으로 써주세요
- 테스트 커버리지 80% 이상 유지해주세요

## 코드 스타일
- TypeScript를 사용합니다
- 함수형 프로그래밍을 선호합니다
```

### AGENT.md는 4곳에 있을 수 있습니다

```
1. ~/.arena-code/AGENT.md        ← 전역 (모든 프로젝트 공통)
2. ./AGENT.md                    ← 프로젝트 (이 프로젝트 전용)
3. ./.arena-code/AGENT.md        ← 로컬 (나만 보는 규칙)
4. ./CLAUDE.md                   ← Claude Code 호환 (있으면 같이 읽음)
```

로봇은 매 대화 시작 시 이 파일들을 **자동으로** 읽습니다!

## 🔄 작동 원리 — 로봇의 하루

로봇이 사람 말을 들었을 때 어떻게 움직이는지 순서대로 봅시다:

```
사람: "계산기 앱을 만들어줘"
  ↓
┌─────────────────────────────────────────────┐
│ 1. 기억 읽기  — AGENT.md, git 상태, 오늘 날짜  │
│ 2. 규칙 확인 — 어떤 도구를 쓸 수 있는지 확인    │
│ 3. 두뇌에게 물어보기 — "계산기를 어떻게 만들까?" │
│ 4. 두뇌가 대답 — "먼저 파일을 살펴봐야겠다! [Glob]"│
│ 5. 손 움직이기 — Glob으로 파일 찾기             │
│ 6. 결과를 두뇌에게 전달 — "파일 목록이야"       │
│ 7. 두뇌가 또 생각 — "이제 코드를 써야겠다! [Write]"│
│ 8. 손 움직이기 — calculator.js 파일 생성        │
│ 9. 결과가 없으면? — 다시 3번으로 돌아가기       │
│ 10. 두뇌가 "다 했어!" 라고 하면 종료            │
└─────────────────────────────────────────────┘
  ↓
로봇: "계산기 앱을 만들었어요! calculator.js를 확인해보세요 🎉"
```

이 반복을 **Agentic Loop**라고 부릅니다:

```javascript
// 아주 간단한 버전
while (true) {
  const response = await 두뇌에게물어보기(대화내용, 도구목록);
  
  if (response.할일없음) break;  // 끝!
  
  for (const 도구 of response.도구들) {
    if (권한검사(도구) === "deny") continue;  // 차단
    if (권한검사(도구) === "ask") 물어보기();
    const 결과 = await 도구실행(도구);
    대화내용에결과추가(결과);
  }
  // 다시 while 처음으로 → 두뇌에게 또 물어보기
}
```

> 핵심: **while(할일이_있으면) → 도구를_쓰고 → 결과를_보고 → 또_생각** 의 반복!

## 🧩 Claude Code와 무엇이 같고 다른가요?

| 구분 | Claude Code (원본) | Arena Code (우리가 만든 것) |
|------|-------------------|---------------------------|
| **두뇌** | Claude만 가능 (유료) | **6가지 중 선택, 공짜 가능!** |
| **손(도구)** | 40+ (많음) | 8개 (핵심만, 충분함) |
| **규칙** | 7단계 (복잡) | 3단계 (간단) |
| **기억** | CLAUDE.md | AGENT.md (CLAUDE.md도 읽음) |
| **가격** | 💰 토큰당 과금 | 🆓 공짜 두뇌로 $0 |
| **작동** | 유료 구독 필요 | 누구나 무료로 사용 |

> 💡 **핵심은 똑같습니다!** — Agentic Loop, 도구 사용, 권한 시스템 모두 동일한 아이디어로 만들었습니다.

## 🎯 정리 — Arena Code는 이런 로봇이에요!

```
Arena Code = 🧠 두뇌(생각) + 🦾 손(도구) + 📖 규칙(권한) + 📝 기억(AGENT.md)

- 🧠 두뇌: 6가지 중 선택 (공짜 가능!)
- 🦾 손: 8가지 도구로 파일을 읽고 쓰고 실행
- 📖 규칙: 위험한 일은 차단, 중요한 일은 물어보기
- 📝 기억: AGENT.md로 프로젝트 규칙 기억
- 🔄 작동: 생각 → 도구 → 결과 → 또 생각 (반복!)
```

이제 이 로봇을 어떻게 사용하는지 배워봅시다!
