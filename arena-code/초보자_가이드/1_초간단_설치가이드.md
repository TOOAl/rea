이 가이드는 그 로봇 비서를 내 컴퓨터에 설치하는 방법입니다!

## 🪜 1단계: Node.js 설치하기 (로봇이 움직이는 엔진)

**Node.js**는 Arena Code가 움직이는 데 필요한 엔진입니다. 없으면 로봇이 작동하지 않아요!

### Windows / Mac 공통

1. 인터넷 브라우저를 열고 아래 주소로 이동:
   ```
   https://nodejs.org
   ```

2. 초록색 버튼 **"LTS 다운로드"** 클릭
   - LTS는 "오랫동안 안정적인 버전"이라는 뜻입니다
   - 버전 숫자는 22 이상이면 됩니다

3. 다운로드된 파일을 더블클릭해서 설치
   - 모든 질문에 **"다음(Next)"** 클릭하면 됩니다
   - 특별히 바꿀 설정은 없습니다!

4. 설치 확인:
   - **Windows**: 키보드에서 `윈도우 키 + R` 누르기 → `cmd` 입력 → 엔터
   - **Mac**: `Spotlight 검색(⌘+Space)` → `Terminal` 입력
   - 검은 화면(터미널)이 열리면 아래 명령어 입력:
     ```
     node -v
     ```
   - `v22.22.3` 같은 숫자가 보이면 성공! ✅
   - 숫자가 안 보이면 컴퓨터를 재시작하고 다시 시도하세요

> ❓ **"node를 인식할 수 없습니다"** 라고 나오면?
> → Node.js 설치가 제대로 안 된 것입니다. 위 과정을 다시 시도하고, 설치 후 컴퓨터를 재시작하세요.

## 🪜 2단계: Arena Code 다운로드하기

### 방법 A: ZIP 파일로 받기 (쉬움)

1. Arena에서 제공된 `arena-code-전체.zip` 파일을 다운로드
   - 또는 GitHub에서 다운로드:
     ```
     https://github.com/TOOAl/rea/archive/refs/heads/arena/f39797b9-rea.zip
     ```

2. 다운로드된 ZIP 파일 찾기:
   - Windows: `내 PC → 다운로드` 폴더
   - Mac: `Finder → 다운로드` 폴더

3. ZIP 파일 우클릭:
   - Windows: **"모두 압축 풀기"** 클릭
   - Mac: 파일을 더블클릭

4. 압축 풀면 `arena-code` 폴더가 생깁니다
   - 이 폴더를 기억하기 쉬운 곳으로 옮기세요
   - 예: `바탕화면/arena-code` 또는 `Documents/arena-code`

### 방법 B: Git으로 받기 (조금 어려움, 선택사항)

터미널에서 아래 명령어 실행:
```bash
git clone -b arena/f39797b9-rea https://github.com/TOOAl/rea.git my-arena-code
cd my-arena-code/arena-code
```

## 🪜 3단계: 필수 부품 설치하기 (npm install)

터미널에서 Arena Code 폴더로 이동한 뒤, 부품을 설치합니다.

1. 터미널 열기:
   - Windows: `arena-code` 폴더 안에서 `Shift + 우클릭` → "여기서 PowerShell 열기"
   - Mac: `arena-code` 폴더 우클릭 → "새 터미널"

2. 아래 명령어를 복사해서 터미널에 붙여넣고 엔터:
   ```bash
   npm install
   ```

3. 잠시 기다리면 (1~2분) 아래 같은 메시지가 나옵니다:
   ```
   added 27 packages, and audited 28 packages in 5s
   ```
   → 성공! ✅

> ❓ **"npm을 인식할 수 없습니다"** 라고 나오면?
> → Node.js 설치가 안 된 것입니다. 1단계로 돌아가세요.

## 🪜 5단계: 공짜 두뇌(API 키) 발급받기

Arena Code는 **두뇌(LLM)**가 있어야 생각할 수 있습니다.
다행히 **공짜 두뇌**를 쓸 수 있습니다! 가장 쉬운 방법을 소개합니다.

### 🌟 추천: Google Gemini (가장 쉽고 관대함)

1. 브라우저에서 아래 주소로 이동:
   ```
   https://aistudio.google.com/app/apikey
   ```

2. Google 계정으로 로그인 (없으면 만들기)

3. 파란 버튼 **"Create API Key"** 클릭

4. 키가 생성됩니다. 모양은 `AIzaSy...` 처럼 생겼습니다
   - 이 키를 **복사**하세요 (Ctrl+C)
   - ⚠️ 이 키는 비밀번호처럼 비밀입니다! 다른 사람에게 보여주지 마세요

### 다른 공짜 두뇌들 (선택사항)

| 이름 | 발급 주소 | 특징 |
|------|----------|------|
| OpenRouter | https://openrouter.ai/keys | 모델이 아주 많음, `deepseek-r1:free` 추천 |
| Groq | https://console.groq.com/keys | 속도가 가장 빠름 |
| Ollama | https://ollama.com | 인터넷 없이도 동작 (로컬) |

> 💡 처음이라면 **Gemini** 하나만 하면 충분합니다!
> 나중에 다른 것도 추가할 수 있습니다.

## 🪜 6단계: 비밀번호 파일 만들기 (.env)

발급받은 키를 프로그램에 알려줘야 합니다.

1. `arena-code` 폴더 안에 `.env.example` 파일이 있습니다
   - 이 파일을 **복사**해서 이름을 `.env`로 바꾸세요
   - Windows: 파일 복사 → 붙여넣기 → 이름 변경
   - Mac: 파일 복사 → 붙여넣기 → 이름 변경

2. `.env` 파일을 메모장으로 열기:
   - Windows: 우클릭 → 연결 프로그램 → 메모장
   - Mac: 우클릭 → 연결 프로그램 → 텍스트편집기

3. 아래 부분을 찾아서 수정:
   ```
   # 수정 전
   GEMINI_API_KEY=
   
   # 수정 후 (발급받은 키 붙여넣기)
   GEMINI_API_KEY=AIzaSyABC123...여기에실제키...
   ```

4. 저장 후 닫기 (Ctrl+S)

> ⚠️ `.env.example`은 그대로 두고, `.env`를 새로 만드는 것입니다!
> `.env` 파일은 절대 다른 사람에게 보내면 안 됩니다.

### .env 파일 예시 (완성된 모습)

```
ARENA_PROVIDER=gemini
GEMINI_API_KEY=AIzaSyD...발급받은키...
GEMINI_MODEL=gemini-2.0-flash

# 나머지는 비워둬도 됩니다
OPENROUTER_API_KEY=
GROQ_API_KEY=
```

## 🪜 7단계: 테스트 — 로봇이 움직이는지 확인!

### 테스트 1: 가짜 모드로 테스트 (API 키 없이도 가능)

```bash
node dist/cli.js --mock -p "안녕! 너는 누구니?"
```

- 로봇이 대답하면 성공! ✅
- 이 모드는 진짜 두뇌 없이도 동작하는 연습 모드입니다

### 테스트 2: 진짜 두뇌로 테스트

```bash
node dist/cli.js -p "1+1은 뭐야?"
```

- `Provider: gemini (gemini-2.0-flash)` 라고 표시되고
- 로봇이 `2`라고 대답하면 성공! 🎉

> ❓ **에러가 나면?**
> - `GEMINI_API_KEY not set` → .env 파일에 키를 제대로 붙여넣었는지 확인
> - `429 Too Many Requests` → 너무 많이 요청함. 1분 기다렸다가 다시 시도
> - `API 키 오류` → 키를 다시 발급받아서 붙여넣기

## 🆘 자주 생기는 문제 해결

| 문제 | 해결 방법 |
|------|----------|
| `node를 찾을 수 없습니다` | Node.js 재설치 + 컴퓨터 재시작 |
| `npm을 찾을 수 없습니다` | Node.js 재설치 (npm은 Node.js에 포함) |
| `permission denied` (Mac) | 명령어 앞에 `sudo` 붙이기: `sudo npm install` |
| `API 키 오류` | .env 파일의 키에 공백이나 따옴표가 들어갔는지 확인 |
| `모델을 찾을 수 없습니다` | `GEMINI_MODEL=gemini-2.0-flash` 로 수정 |
| 터미널이 어디 있는지 모르겠음 | Windows: 시작 → "cmd" 검색 / Mac: Spotlight → "Terminal" |
