## 📦 방법 1: ZIP 파일로 한 번에 다운로드 (가장 쉬움)

### Arena 환경에서 다운로드

1. **ZIP 만들기** (이미 만들어져 있습니다!)
   ```bash
   # 터미널에서 실행 (이미 완료된 상태일 수 있음)
   cd /home/user/rea
   zip -r arena-code-전체.zip arena-code -x "arena-code/node_modules/*" "arena-code/dist/*"
   ```

   👉 만든 파일 위치: `/home/user/rea/arena-code-전체.zip`

2. **다운로드**
   - Arena 파일 탐색기에서 `arena-code-전체.zip` 파일을 찾아 다운로드 버튼 클릭
   - 또는 아래 **"파일 보기"**로 열린 파일을 다운로드

3. **로컬에서 압축 풀기**
   - Windows: 파일 우클릭 → "모두 압축 풀기"
   - Mac: 파일 더블클릭
   - 압축 풀면 `arena-code` 폴더가 생깁니다

> 💡 `node_modules`와 `dist`는 ZIP에서 제외했습니다.
> 로컬에서 `npm install`과 `npm run build`로 다시 생성하면 됩니다. (아래 설치 가이드 참조)

### Git으로 다운로드 (개발자용)

```bash
# Git이 설치된 경우
git clone -b arena/f39797b9-rea https://github.com/TOOAl/rea.git my-arena-code
cd my-arena-code/arena-code
npm install
```
