## 1. 첫 대화 — "안녕"이라고 말하기

### 준비

터미널을 열고 `arena-code` 폴더로 이동:
```bash
cd arena-code
```

### 방법 A: 한 번만 말하기 (빠른 모드)

```bash
node dist/cli.js --mock -p "안녕! 너는 누구니?"
```

- `--mock`: 가짜 두뇌 모드 (API 키 없이도 됨, 연습용)
- `-p "안녕!..."`: 한 번만 말하고 끝내기

결과:
```
[MOCK Arena Agent]
요청: "안녕! 너는 누구니?"
...
🔧 Glob(pattern="**/*") → 파일 목록 표시
✅ 완료
```

### 방법 B: 계속 대화하기 (대화형 모드)

```bash
node dist/cli.js --mock
```

결과:
```
🤖 Arena Code v1.0.0
   Provider: arena (arena-agent)
   CWD: /home/user/rea/arena-code

💬 Interactive mode — 메시지를 입력하세요. 'exit'로 종료.

❯ 
```

여기서 계속 입력할 수 있습니다:
```
❯ 안녕!
❯ 이 프로젝트가 뭐하는 프로젝트야?
❯ exit
```

> 💡 **exit** 또는 **quit**를 입력하면 대화가 끝납니다.

## 3. 버그 찾기 — 탐정 놀이 🕵️

버그가 있는 예제 프로젝트로 연습해봅시다.

### 예제 프로젝트 만들기

```bash
# 예제 프로젝트 생성 (자동으로 만들어줌)
bash examples/test-project.sh

# 확인
ls /tmp/demo-project/
# AGENT.md  package.json  src/
cat /tmp/demo-project/src/math.js
```

`math.js` 내용:
```javascript
function add(a, b) { return a + b; }
function divide(a, b) { return a / b; } // 버그: b=0 처리 없음
function factorial(n) {
  if (n === 0) return 1;
  return n * factorial(n - 1); // 버그: 음수 처리 없음
}
```

### 버그 찾기 시키기

```bash
node dist/cli.js -p "다음 파일을 분석해서 버그를 찾아줘: /tmp/demo-project/src/math.js" --provider gemini --cwd /tmp/demo-project
```

**로봇이 하는 일:**
1. 🔧 Read → `math.js` 읽기
2. 🧠 분석 → "버그 2개를 찾았습니다:
   - `divide` 함수: 0으로 나누면 Infinity가 됩니다
   - `factorial` 함수: 음수를 넣으면 무한 반복으로 멈춥니다"

> 💡 `--cwd /tmp/demo-project`는 "작업 폴더를 여기로 해줘"라는 뜻입니다.

## 4. 버그 고치기 — 의사 놀이 🩺

찾은 버그를 고쳐봅시다:

```bash
node dist/cli.js --provider gemini --cwd /tmp/demo-project -p "
/tmp/demo-project/src/math.js 파일의 버그를 고쳐줘:
1. divide 함수가 0으로 나눌 때 에러를 던지도록
2. factorial 함수가 음수일 때 에러를 던지도록
3. 각 함수에 JSDoc 주석도 추가해줘
"
```

**로봇이 하는 일:**
1. 🔧 Read → 파일 읽기
2. 🔧 Edit → `divide` 함수 수정
3. 🔧 Edit → `factorial` 함수 수정
4. 🔧 Bash → 수정 확인 (필요시)

**결과 확인:**
```bash
cat /tmp/demo-project/src/math.js
```

고쳐진 코드 예시:
```javascript
/**
 * 두 수를 나눕니다
 * @param {number} a - 나눌 수
 * @param {number} b - 나누는 수 (0 불가)
 * @returns {number} 나눗셈 결과
 */
function divide(a, b) {
  if (b === 0) throw new Error("0으로 나눌 수 없습니다");
  return a / b;
}

/**
 * 팩토리얼을 계산합니다
 * @param {number} n - 0 이상의 정수
 * @returns {number} 팩토리얼 결과
 */
function factorial(n) {
  if (n < 0) throw new Error("음수의 팩토리얼은 계산할 수 없습니다");
  if (n === 0) return 1;
  return n * factorial(n - 1);
}
```

> ✅ **권한 요청**이 뜨면?
> ```
> ❓ 권한 요청: Edit — Edit(/tmp/demo-project/src/math.js)
>    허용? [Y/n]
> ```
> → `Y`를 입력하고 엔터 (또는 그냥 엔터 — 기본값이 Yes)

## 6. AGENT.md 커스터마이징 — 규칙 정하기 📏

로봇에게 "이렇게 행동해"라고 규칙을 정할 수 있습니다.

### AGENT.md 만들기

`arena-code` 폴더에 `AGENT.md` 파일을 만들고 규칙을 적습니다:

```markdown
# 우리 프로젝트 규칙

## 코드 스타일
- 모든 함수는 JSDoc 주석 필수
- 변수 이름은 영어로, 알아보기 쉽게

## 작업 방식
- 파일 수정 전에 항상 먼저 읽어보기
- 복잡한 작업은 TodoWrite로 계획부터 세우기
- 수정 후에는 테스트 실행하기

## 말투
- 한국어로 대답하기
- 초보자가 이해할 수 있도록 쉽게 설명하기
```

### 효과

```bash
# AGENT.md를 만든 후
node dist/cli.js -p "새 함수 하나 만들어줘"
# → 로봇이 AGENT.md 규칙을 자동으로 따라 JSDoc을 붙이고 한국어로 설명합니다!
```

### AGENT.md는 4곳에 둘 수 있어요

```
1. ~/.arena-code/AGENT.md        ← 모든 프로젝트 공통 (전역)
2. ./AGENT.md                    ← 이 프로젝트 전용 (프로젝트)
3. ./.arena-code/AGENT.md        ← 나만 보는 규칙 (로컬)
4. ./CLAUDE.md                   ← Claude Code 호환 (있으면 같이 읽음)
```

## 7. 대화형 vs 한 번 모드

### 대화형 모드 (계속 대화) — 추천! ⭐

```bash
node dist/cli.js
```

```
❯ 이 프로젝트 구조를 설명해줘
  (로봇이 탐색하고 설명)

❯ 그럼 버그를 찾아줘
  (이전 대화 기억하면서 버그 찾기!)

❯ 찾은 버그를 고쳐줘
  (버그 내용을 기억하면서 고치기!)

❯ exit
```

- ✅ 이전 대화를 기억합니다
- ✅ 여러 단계를 이어서 할 수 있습니다
- ✅ 가장 자연스러운 사용법

### 한 번 모드 (한 질문하고 끝)

```bash
node dist/cli.js -p "버그를 찾아줘"
```

- ✅ 스크립트나 자동화에 좋음
- ✅ 한 번만 하고 끝낼 때
- ❌ 이전 대화를 기억하지 못함 (매번 새로 시작)

### 명령어 옵션

```bash
node dist/cli.js --help

옵션:
  -p, --print <질문>         한 번 모드
  --provider <이름>          두뇌 선택 (gemini, openrouter, groq, ollama, arena)
  --model <모델이름>         두뇌 모델 지정
  --max-turns <숫자>         최대 반복 횟수 (기본 20)
  --cwd <경로>               작업 폴더 지정
  --mock                     가짜 모드 (연습용)
  --dangerously-skip-permissions  권한 검사 건너뛰기 (위험!)
```

### 특수 명령어 (대화형 모드 안에서)

```
❯ /help     도움말 보기
❯ /clear    대화 초기화 (기억 지우기)
❯ /status   현재 상태 확인
❯ exit      종료 (quit, /exit도 가능)
```

## 🆘 문제가 생겼을 때

| 문제 | 해결 방법 |
|------|----------|
| 로봇이 이상한 대답을 함 | 더 구체적으로 말해보세요: "src/math.js의 divide 함수"처럼 파일명 명시 |
| 권한 요청이 계속 뜸 | `.arena-code/settings.json`에서 allow 목록에 추가하거나 `--dangerously-skip-permissions` 사용 |
| `Max turns reached` | `--max-turns 30`으로 늘리기 |
| 느리게 동작함 | `--provider groq`로 바꾸면 가장 빠름 |
| 대화가 너무 길어짐 | `/clear`로 대화 초기화 후 다시 시작 |
| API 키 오류 | `.env` 파일 확인, 키 재발급 |
