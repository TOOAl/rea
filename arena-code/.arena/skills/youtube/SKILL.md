# /youtube — 기사/주제로 유튜브 수익화 영상 자동 생성

1층에 입력한 기사/주제를 5층 파이프라인으로 8분 팩트체크 영상으로 변환합니다.

## 입력 방법 (1층)

- `node dist/cli.js --topic "코스피 급락" --article-file ./article.txt -p "/youtube 코스피 분석해줘"`
- 대화: `/topic 코스피 급락` → `/article 오늘 코스피가...` → `/youtube 8분 대본 만들어줘`
- `/article-url https://n.news.naver.com/...` 로 URL 직접 가져오기

> 1층 입력은 `Brains({ task, article, topic })`로 자동 전달되며, CLI 입력이 있으면 Brains 호출 시 자동 주입됩니다.

## 5층 실행 순서

1. 1층 필터: 사실/해석/추측 3색 분류, 금융 단정어 차단
2. 2층 설계: 5단계 구조 (목표고정→사실분리→용량점검→중단기준→대안3개)
3. 3층 창의: HISTORY 36 비교 스토리
4. 3.5층 게이트: 금융·선정성 8인 심사
5. 4층 토론 + 5층 합의: 최종 7종 산출물

## 출력물 7종

- 대본: `docs/youtube_자동생성/[주제]_대본_수익화.md`
- 제목 3안, 설명란, 태그, 썸네일 프롬프트, 자막(.srt), 수익화 체크리스트
- 참고 템플릿: `docs/youtube_코스피_급락_대본_수익화.md` 등
