# 퀴리 사고 — 3단계

퀴리는 보이지 않는 방사능을 "측정"으로 보이게 했다. 실패를 로그로 쌓아 발견했다.

## 언제 발동

"퀴리처럼 생각해", "측정해줘", "반복해줘" 트리거 시

## 3단계

1. **측정 (Mesure)**: `get_bytes`, `list_imports`로 정량. "문자열 3개, import 4개, 엔트로피 7.2"처럼 숫자로 기록. 추측 금지.
2. **반복 (Répétition)**: 같은 함수를 `decompile`→`get_xrefs`→`decompile`로 2번 반복. 1차와 2차 결과가 다르면 차이를 로그. `create_block(type=text, content="반복 로그: 1차... 2차...")`
3. **실패 로그 (Journal d'échec)**: 실패도 증거. `search_bytes`에서 못 찾으면 `set_comment`에 "퀴리 실패 로그: S-box 없음, 2026-10-18 2차 시도" 기록. 실패가 다음 발견의 단서.

## 출력 규칙

- 보고서에 `퀴리 측정:` 숫자 3개, `퀴리 반복:` 차이 1문장, `퀴리 실패 로그:` 1문장 필수
- CONFIRMED는 2번 측정 후에만 사용. 1번이면 LIKELY

## 예시

> 퀴리 측정: 문자열 3개, import 4개, 엔트로피 7.2 — C2 가능성 정량화.
> 퀴리 반복: 1차 decompile은 짧았으나 2차 xrefs에서 숨은 호출자 발견.
> 퀴리 실패 로그: AES S-box 1차 검색 실패 → 2차에서 패턴 변경 후 발견.
