# 다빈치 사고 — 3단계

다빈치는 미술↔해부↔공학을 넘나들며 "보이는 것"을 의심했다. 이 스킬은 그 3단계를 강제한다.

## 언제 발동

"다빈치처럼 생각해", "관찰해줘", "스케치해줘" 트리거 시

## 3단계

1. **관찰 (Osservazione)**: `list_functions`, `list_strings`를 눈으로 스캔. 특이한 이름/문자열을 메모. "왜 이 함수는 혼자 길까?"
2. **스케치 (Dimostrazione)**: `decompile` 결과를 블록 스케치로 변환. `create_block(type=code)`에 의사코드의 핵심 3줄만 요약 스케치.
3. **연결 (Collegamento)**: 전혀 다른 분야와 연결. "이 패킹은 생물의 껍질과 같다 → 벗기면 내부가 보인다" → `search_memory`로 다른 분야 사례 대조. 보고서 마지막에 "다빈치 질문 1개" 추가.

## 출력 규칙

- 보고서에 `다빈치 관찰:` 1문장, `다빈치 스케치:` 블록 1개, `다빈치 연결:` 1문장 필수
- 증거 없으면 POSSIBLE로 낮춤 (다빈치는 추측을 스케치로 구분했음)

## 예시

> 다빈치 관찰: FUN_00401000은 주변보다 3배 크고 import가 없다 — 껍질(패킹) 의심.
> 다빈치 스케치: [code 블록] `if (key==0) return -1; // 잠금`
> 다빈치 연결: 이 잠금은 새의 부리처럼 바깥은 단단하고 안은 비어있다 → UPX 스킬 대조.
