# 5층+3.5게이트 아키텍처 — v2.23.0 (12살용 + 전문가용)

> **한 문장:** 1층에 안내원 3명, 2층에 전략가 3명, 3.5층에 검증 문을 달아 건물을 더 똑똑하게 만들었다.

## 12살 설명

우리 건물은 이제 5층이 아니라 **5층 + 3.5층 문**이야. 엘리베이터는 1→2→3→3.5→4→5 순서로 한 번만 올라가.

* **1층 기억도서관 8명:** 기존 사서·탐정 5명에 `기억천재·언어천재·맥락천재` 3명이 추가. 네가 “AI 문서 관리해줘”라고 말하면, 언어천재가 뜻을 풀고, 기억천재가 “그 기억은 2번 서랍에 있어”라고 지도 찍고, 맥락천재가 “이때 필요한 건 이 3개야”라고 골라준다.
* **2층 설계사무실 6명:** 기존 건축가 1명+2명에 `역사전략가·경영전략가·공학설계가` 3명이 추가. 손자·드러커·NASA가 알려준 “목표부터 고정, 중단기준 미리, 검증계획 짜기”를 도면에 넣는다.
* **3층 창의공방 3명:** 야생 아이디어 3개 → 비판 3문항.
* **3.5층 게이트(새로 만든 문):** 30명 천재 중 **과제에 꼭 필요한 7명 + 와일드카드 1명**을 뽑아 6/8 이상 O면 통과, 아니면 아래층으로 돌려보낸다(최대 2번).
* **4층 토론정원:** 이제 “각자 자기 주장”이 아니라 “모두가 한 안을놓고 토론해 최고안 만들기”.
* **5층 의회:** 투표·합의.

```
1층 8명 → 2층 6명 → 3층 3명 → 3.5층 게이트(8명 투표) → 4층 토론(18명) → 5층 의회
   지도       설계      아이디어      검증 문              토론          합의
```
