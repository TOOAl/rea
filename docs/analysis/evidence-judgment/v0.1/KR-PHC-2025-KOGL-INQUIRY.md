## Verification checklist when a reply arrives

- Record the response date, official sender/office, and the exact type for **each** file separately.
- If a cover image is supplied, preserve it with the reply context and visually read the mark; do not infer the XLS type from the PDF or vice versa.
- Check whether the stated conditions permit the intended use before changing `rights_status` or setting `approved_for_packet=true`.
- If the office says no KOGL mark applies, record the exact written conditions/permission; do not substitute a generic portal notice.
