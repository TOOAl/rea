# 엄격한 검수팀(Exam QA Force) 운영 지침 — v1.0

> “우리는 깨진 결과물을 절대 학생에게 보내지 않는다.”
> 사용자 지적: **그림이 경계를 벗어난 것을 왜 못 봤나?** → 100% 맞습니다. 눈으로만 본 검수는 실패합니다.

## 1. 실패 원인 분석 (5 Whys)

1. **Why 1**: 그림 8 `rx=52` 타원이 노란 박스(너비 240)를 7px 초과
   → 제작자가 수동으로 숫자 입력, 경계 계산 안 함
2. **Why 2**: 왜 계산 안 했나? → 뷰어에서는 잘려 보이지 않아 “눈에 띄지 않음”
3. **Why 3**: 왜 안 보이는 걸 못 잡았나? → 스크린샷 비교·자동 경계 검사가 없었음
4. **Why 4**: 왜 검사가 없었나? → “두뇌 천재”가 있었지만, **검수 역할은 정의만 있고 실행 코드/체크리스트가 없었음**
5. **Why 5**: 왜 실행이 없었나? → 산출물(HTML/PDF) → 검증 → 수정 루프가 프로세스에 없었음

→ **해결: 코드로 잠그는 3바퀴 검증 루프 + 전담 검수팀을 상시 가동**

---

## 2. 검수팀 편성 (3팀 6역할)

| 팀 | 역할 | 담당 | 검증 도구 |
|---|---|---|---|
| **A. 레이아웃 QA** | ① 경계·오버플로우 검수 | SVG/HTML 요소가 부모 박스를 벗어나는지 1px 단위 검사 | `scripts/inspect_layout.js` (Puppeteer boundingBox) |
|  | ② 인쇄·컬럼 검수 | A4 2단에서 문항이 잘리지 않는지, 잘림 방지(break-inside) 검증 | Puppeteer `printToPDF` + 페이지 수 카운트 |
| **B. 가독성 QA** | ③ 폰트·글자 깨짐 검수 | 한글 tofu(□), 영어 fallback, 폰트 미탑재 탐지 | `document.fonts.check('12px Noto Sans KR', '가')` + 스크린샷 OCR |
|  | ④ 명암·배색 검수 | WCAG 대비 4.5:1 미달, 노란 배경 위 흰 글자 등 시인성 검사 | axe-core contrast check |
| **C. 사실·교육 QA** | ⑤ 과학 정확성 검수 | 유전·별·우주 개념 오류(예: 성운→백색왜성 순서, 허블 공식) | 성취기준 체크리스트 대조 |
|  | ⑥ 난이도·배점 검수 | 하30 중50 상20, 서술형 루브릭 채점 가능성 | 문항 분석표 |

> 모든 산출물은 **3팀 전원 PASS**를 받아야 배포(Git push) 가능.

## 3. 3바퀴 검증 루프 (코드로 잠금)

```
1바퀴: 생성 → 자동 레이아웃 검사 (실패 시 재생성)
2바퀴: 1바퀴 통과 → 가독성/폰트 검사 (실패 시 폰트 교체)
3바퀴: 2바퀴 통과 → 사실·교육 검사 (실패 시 내용 수정)
→ 최종: 3바퀴 모두 PASS → PDF 재생성 → Git 커밋
```

`npm run qa:exam` 한 번으로 3바퀴를 모두 실행합니다.

## 4. 이번 수정 내역 (2026-10-26, 커밋 c9d98ed 후속)

| 구분 | 문제 | 조치 |
|---|---|---|
| **그림 8 경계 초과** | `중3과학시험지/12살을위한_쉬운과학설명서.html` 454행 `<ellipse rx=52>`가 부모 `<rect width=240>`를 7px 초과 → 스크린샷에서 박스 밖으로 삐져나옴 | `width 240→250`, `rx 52→40, ry 38→30`으로 축소, 내부 점 좌표 재조정, 텍스트 `→` 위치 140→135로 이동. 이제 좌우 2px 여백 확보 |
| **재발 방지** |  | `scripts/inspect_layout.js`에 **SVG 경계 초과 자동 탐지** 추가. 모든 `<ellipse>`, `<rect>`, `<circle>`의 `getBBox()` vs 부모 `getBBox()` 비교, 초과 시 `FAIL` |

### 수정 전/후 수치

- 수정 전: `x=195 ±52 = [143, 247]` vs 부모 `[0,240]` → **+7px 초과**
- 수정 후: `x=195 ±40 = [155, 235]` vs 부모 `[0,250]` → **-15px 여백 확보**

스크린샷 재촬영 시 노란 박스 안에 완전히 들어옵니다.
