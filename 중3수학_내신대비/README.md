# 중학교 3학년 수학 내신 대비 변별력 50제

미래엔 중학교 수학 3-2(2015 개정 교육과정) 범위의 내신 대비 자료입니다.

## 산출물 (PDF 2종, A4 / 여백 10mm / 2단)

| 파일 | 쪽수 | 내용 |
| --- | --- | --- |
| `중3수학_변별력50제_문제편.pdf` | 12쪽 | 표지(트렌드 분석·구성표) + 50문항 |
| `중3수학_변별력50제_정답과해설.pdf` | 23쪽 | 정답표 + 자가 채점 기준 + 문항별 정답·핵심 개념·단계별 풀이·합격 팁 |

## 출제 범위

1. 원주각과 그 성질 (1~12번)
2. 원에 내접하는 사각형의 성질 (13~20번)
3. 원의 접선과 현이 이루는 각 (21~28번)
4. 대푯값: 평균·중앙값·최빈값 (29~35번)
5. 산포도: 분산과 표준편차 (36~43번)
6. 산점도와 상관관계 (44~50번)

## 문항 구성

- 총 50문항: 선택형 21 · 단답형 17 · 서술형 및 신유형 12
- 난이도: 하 13(26%) · 중 24(48%) · 상 13(26%)
- 45문항에 직접 제작한 원 도형·막대그래프·점도수·산점도 수록

## 반영한 최근 기출 트렌드

1. **서술형·과정 중심 평가 확대** — 전국 중학교 기출에서 서답형 2~3문항이 기본 편성되어 풀이 과정과 근거 서술 요구
2. **단원 융합·다단계 추론** — 원주각·내접사각형·접현각 융합 문항, 대푯값·산포도 의사결정 문항
3. **실생활 소재** — 슈팅 각도, 측량, 용돈 통계, 선수 선발, 난방비, 매출 그래프
4. **공학적 도구 활용(신유형)** — 엑셀 AVERAGE·VAR·STDEV 결과 해석 (42번)
5. **오류 분석·비판적 사고(신유형)** — 친구 풀이 오류 교정(11, 20, 28번), 그래프 왜곡 비판(49번), '상관 ≠ 인과'(47번)
6. **역추론·개념 본질** — 각도·x 거꾸로 구하기, '어느 호에 대한 원주각인가' 판별, 편차의 합 0 활용

> 트렌드는 2025학년도 전국 중학교 기출 분석 자료, EBS 내신 대비 강좌 구성,
> 2015/2022 개정 수학과 교육과정 성취기준(9수05-06~08)을 조사하여 반영했습니다.

## 재빌드 방법

```bash
python3 -m venv .venv
.venv/bin/pip install reportlab pypdfium2
# 한글 폰트(NanumGothic·NanumMyeongjo TTF)를 이 폴더의 fonts/ 또는 /home/user/fonts/ 에 배치
# 출처: npm @kfonts/nanum-gothic, @kfonts/nanum-myeongjo (src/*.ttf)
.venv/bin/python build_exam.py
```

- `engine.py`: PDF 레이아웃·도형(원/막대/점도수/산점도) 드로잉 엔진
- `data_geo1.py`, `data_geo2.py`, `data_stats.py`: 50문항 데이터
- `build_exam.py`: 문제편·해설편 PDF 조립
