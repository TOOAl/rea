# 중학교 3학년 수학 내신 대비 문항집

미래엔 중학교 수학 3-2(2015 개정 교육과정) 범위의 내신 대비 자료입니다.
기본·중상·고난도를 아우르는 **변별력 50제**와, 상위권 변별 문항만 모은 **고난도 20제** 두 세트로 구성됩니다.

## 산출물 (각 세트마다 문제편·해설편 분리, A4 / 여백 10mm / 2단)

### 세트 1 — 변별력 50제 (하 26% · 중 48% · 상 26%)

| `중3수학_변별력50제_문제편.pdf` | 12쪽 | 표지(트렌드 분석·구성표) + 50문항 |
| `중3수학_변별력50제_정답과해설.pdf` | 23쪽 | 정답표 + 자가 채점 기준 + 문항별 정답·핵심 개념·단계별 풀이·합격 팁 |

| `중3수학_고난도20제_정답과해설.pdf` | 10쪽 | 정답표 + 자가 채점 기준 + 문항별 정답·핵심 개념·단계별 풀이·합격 팁 |

## 출제 범위 (두 세트 공통)

1. 원주각과 그 성질
2. 원에 내접하는 사각형의 성질
3. 원의 접선과 현이 이루는 각
4. 대푯값: 평균·중앙값·최빈값
5. 산포도: 분산과 표준편차
6. 산점도와 상관관계

## 문항 구성

### 50제
- 선택형 21 · 단답형 17 · 서술형 및 신유형 12
- 45문항에 직접 제작한 원 도형·막대그래프·점도수·산점도 수록

### 고난도 20제
- 선택형 7 · 단답형 7 · 서술형 및 신유형 6 (전 문항 '상' 난이도)
- 단원 융합·다단계 추론(원주각+피타고라스, 내접사각형+대각선 삼각형), 역추론,
  오류 분석, 상관과 인과 구분, 자료 변환 추론 등 상위권 변별 유형 집중 편성
- 50제와 문항이 중복되지 않는 신규 출제

## 반영한 최근 기출 트렌드

1. **서술형·과정 중심 평가 확대** — 풀이 과정과 근거 서술을 요구하는 문항
2. **단원 융합·다단계 추론** — 원의 성질 내 융합, 대푯값·산포도 의사결정
3. **실생활 소재** — 슈팅 각도, 측량, 급여·용돈 통계, 선수 선발, 난방비, 매출 그래프
4. **공학적 도구 활용(신유형)** — 엑셀 AVERAGE·VAR·STDEV 결과 해석
5. **오류 분석·비판적 사고(신유형)** — 친구 풀이 오류 교정, 그래프 왜곡 비판, '상관 ≠ 인과'
6. **역추론·개념 본질** — 각도·미지값 거꾸로 구하기, '어느 호에 대한 원주각인가' 판별, 편차의 합 0

> 트렌드는 2025학년도 전국 중학교 기출 분석 자료, EBS 내신 대비 강좌 구성,
> 2015/2022 개정 수학과 교육과정 성취기준(9수05-06~08)을 조사하여 반영했습니다.
> 계산이 포함된 문항의 정답은 독립 스크립트로 전수 재계산하여 검증했습니다.

## 재빌드 방법

```bash
python3 -m venv .venv
.venv/bin/pip install reportlab pypdfium2 fonttools
# 한글 폰트(NanumGothic·NanumMyeongjo TTF)를 fonts/ 또는 /home/user/fonts/ 에 배치
# 출처: npm @kfonts/nanum-gothic, @kfonts/nanum-myeongjo (src/*.ttf)
.venv/bin/python build_exam.py      # 변별력 50제
.venv/bin/python build_hard20.py    # 고난도 20제
```

- `engine.py`: PDF 레이아웃·도형(원/막대/점도수/산점도) 드로잉 엔진 (두 세트 공용)
- `data_geo1.py`, `data_geo2.py`, `data_stats.py`: 50제 문항 데이터
- `data_hard20.py`: 고난도 20제 문항 데이터
- `build_exam.py`, `build_hard20.py`: 각 세트 PDF 조립 스크립트
